## Findings

### 1. 走行中の画面注視・操作

- 車両停止時を除く画像注視を前提にしない。
- 操作が必要な場合は安全な場所へ停車してから行う。
- 走行中の通知タップ、再読込、詳細確認を誘発しない。
- Repositoryの走行安全UI方針と整合している。

### 2. JARTICコンテンツ

- 一般公開ウェブページの無断第三者表示、公衆送信、転載、改変、類似サービス流用を前提にしない。
- ウェブページをスクレイピングして再表示しない。
- オープンデータ・契約データは個別提供条件を確認する。

### 3. オービス表示粒度

- 一般的な安全運転注意は許容。
- 地域・路線単位の粗い表示は条件付き候補。
- 正確座標は法務・提供元・地域運用・ストア審査確認まで未承認。
- 移動式リアルタイム情報、ユーザー投稿型正確地点、取締り回避ルートはMVP禁止。

### 4. 通知

- 走行中のプッシュ通知・ポップアップはMVP禁止。
- 正確地点接近時の音声通知は要専門確認・MVP未採用。
- 安全運転の一般的な事前注意は条件付き候補。

### 5. 地域差

- 都道府県・警察署単位で事故実態等に基づく速度取締り指針が策定される。
- 公表重点路線・時間帯だけで取締り範囲を断定しない。
- 地域、基準日、発表主体を保持する。

## Decisions

- Issue #93は法的助言ではなく、後続設計の判断ゲートを定義するレビューとする。
- 確定要件、条件付き許容候補、MVP禁止、要専門確認に区分する。
- 正確座標、接近通知、音声通知は本Issueで採用しない。
- JARTICウェブページのスクレイピング再表示を禁止する。
- データ提供元採用前に、再配布・加工・キャッシュ・帰属・停止条件を確認する。
- 判断不能時はNo-Goとする。

## Rejected Alternatives

- オービス通知アプリが存在することを理由に適法・採用可能と判断する案: 公式根拠にならないため不採用。
- 公開取締り情報をそのまま正確地点通知へ利用する案: 利用条件・目的・地域運用・安全性が未確認のため不採用。
- JARTICウェブページをスクレイピングする案: 利用規約上の制限と権利リスクがあるため不採用。
- 公表された重点路線以外では取締りがないと表示する案: 公的資料が保証していないため不採用。
- AI判断だけで法務レビュー完了とする案: 人間レビュー必須方針に反するため不採用。

## Risks

- 地域別運用差を全国一律仕様として扱うこと。
- 安全運転目的の文言でも、通知・正確地点表示が取締り回避や画面注視を助長すること。

- 提供停止・訂正・通報・監査の責任者が未定義のまま実装へ進むこと。
