## Confirmed Findings

- Routes API結果を地図上に表示する場合はGoogle Mapを使用する。
- Routes APIのGoogle Maps Contentは地図なしでも利用できるが、Google Maps帰属が必要。
- Routes APIのGoogle Maps Contentを非Google地図と組み合わせて使用しない。
- Google Maps ContentとRouteGarage独自・第三者コンテンツは視覚的に区別する。
- Customer Applicationには一般公開された利用規約・プライバシーポリシーが必要。
- Google IDのうち、Documentationが許可するPlace IDは保存可能。
- EEA外向け現行Service Specific Termsでは、Routes API出力の緯度・経度を最大30暦日一時キャッシュできる。
- Routes APIはGoogle Maps Platform Core Services Summaryに掲載されている。
- Google Maps Platform SLAはCovered Serviceに対する99.9% SLOを示すが、契約・除外・請求条件の確認が必要。
- HTTPSとAPIキー制限がGoogle公式のセキュリティ推奨事項である。

## Technical Decisions

- C-01の評価は`条件付き候補を維持 / 基本設計前提としては保留`とする。
- Google Map上に表示する結果と地図なし表示を分離する。
- 非Google地図とGoogle Routesを同一ルート判断機能で組み合わせない。
- Place IDは長期保存候補とする。
- Google出力の緯度・経度は、適用契約確認後も最大30日以内の期限付き保存候補とする。
- polyline、distance、duration、traffic情報、route response全体は永続保存しない。
- Google Routes結果を長期交通統計、比較分析、学習データ、共通ルートDBへ転用しない。
- RouteGarage内部request ID、HTTPステータス、レイテンシ等は、正確な位置・Google Contentを含まない運用メタデータ候補とする。
- ユーザー入力とGoogle Maps Contentを別データとして管理する。
- SLAとRouteGarageの利用者向けSLOを同一視しない。
- 採用時は別IssueとADRを作成する。

## Safety / Privacy Decisions

- origin / destination等の生リクエストを通常ログへ保存しない。
- Googleへの送信情報とRouteGarage内の走行履歴を長期結合しない。
- 自宅・職場・生活圏に関係する位置情報は、送信必要性・同意・代替手段を別途レビューする。
- 走行中の注視・操作・能動通知を前提にしない。
- ルート・交通情報を安全判断の唯一の根拠にしない。
- 情報源、再計算要否、取得失敗、鮮度不明を区別できない構成はNo-Go。
- 取締り回避目的のルート・表示・通知を扱わない。

## Rejected Alternatives

- Google Maps Platformが優先候補であることを採用決定として扱う案
  - 契約主体・請求先・適用文書・人間承認が未確定のため不採用。
- Routes APIレスポンス全体を走行履歴へ保存する案
  - キャッシュ・保存許可を確認できず、代替データベース化につながるため不採用。
- polyline、distance、duration、traffic情報を長期分析する案
  - 保存・派生データ作成の許可を確認できないため不採用。
- Google Routes結果を非Google地図へ表示する案
  - 現行Service Specific Termsの非Google地図併用禁止と整合しないため不採用。
- API失敗時に保存済みルート結果を無期限再表示する案
  - 保存期限・鮮度・安全性を満たせないため不採用。
- request / response全体をデバッグログへ保存する案
  - 正確な位置情報、Google Maps Content、秘密情報が混入するため不採用。

## Risks

- 契約主体の請求先住所によってEEA / 非EEAの適用規約が変わること。
- 公開ポリシーの更新をRepositoryへ反映できないこと。
- Google出力座標とユーザー自身の座標を混同すること。
- backup、analytics、debug dumpへGoogle Maps Contentが残ること。
- RouteGarage独自データとGoogle Maps Contentの帰属が混在すること。
- Place ID以外のGoogle Maps Contentを長期保存可能と誤認すること。
- Google SLAをRouteGarage利用者への可用性保証として誤表示すること。
- 位置情報送信と走行履歴を長期結合し、生活圏推定リスクを高めること。
