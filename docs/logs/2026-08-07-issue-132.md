## 主な決定

### コレクション

- 初期はRouteGarage運営編集のみ。
- ユーザー生成コレクションは対象外。
- 既存スポット参照方式。
- `DRAFT` / `REVIEW_REQUIRED` / `PUBLISHED` / `STOPPED` / `ARCHIVED`。
- `STOPPED`を最優先。

### 進捗

- 手動自己申告で訪問済み登録。
- GPS位置証明を要求しない。
- 走行記録参照は任意。
- 走行記録から自動訪問確定しない。
- `NOT_STARTED` / `IN_PROGRESS` / `COMPLETED`。

### 版管理

- 構成変更は`content_revision`。
- 達成記録は特定版へ紐づける。
- 新版公開後も旧版達成を保持。
- 現在版進捗と旧版達成を分ける。

### 安全

- 走行中チェックインなし。
- ランキングなし。
- 最速・速度・距離競争なし。
- ストリークなし。
- コレクション順を推奨経路として扱わない。

### プライバシー

- 保存、訪問履歴、達成記録は本人限定を初期値とする。
- 正確位置・移動軌跡を追加取得しない。
- 訪問日時は任意。
- 将来のバッジ公開でも訪問順・正確位置・速度を自動公開しない。

### コンテンツ

- 初期テーマ候補を定義。
- 実在スポット・実画像は投入しない。
- 第三者説明文をコピーしない。
- 権利不明画像を公開しない。
- 季節・施設・通行条件の再確認を要求。
- AI生成案だけで公開しない。
