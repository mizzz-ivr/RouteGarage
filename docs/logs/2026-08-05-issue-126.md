## 1. 目的

JARTIC交通規制情報について、実データを取得する前に、公開資料と公開済み公式説明書から確認できる上流由来、第三者権利、意味・鮮度・安全上の境界を整理する。

## 2. タスク選定理由

PR #125 / Issue #124で断面交通量情報のプレフライトが完了したため、未着手3データセットから安全影響が最も大きい交通規制情報を選定した。

交通規制情報は、位置・方向・対象車両・期間・例外の誤解釈が通行違反や事故誘発につながる可能性がある。JARTIC公開ページと公式説明書では、自動運転・安全運転支援での活用を目的に拡張版標準フォーマットが策定されたと説明されるため、単なる権利確認だけでなく安全利用境界の定義が必要である。

## 4. 公開資料から確認した事実

- 元データは各都道府県警察が保有する交通規制DBである。
- JARTICが拡張版標準フォーマットへ変換して都道府県単位で公開する。
- 公開説明上のフォーマットは`拡張版_K_2.1`である。
- 作成基準日・版は別の「作成基準日等データ」で確認する必要がある。
- 原則月次更新で、旧公開版は取得できなくなる。
- 拡張版標準フォーマットは警察庁がSIP第2期調査研究で取りまとめた。
- 自動運転・安全運転支援での活用と、規制方向情報の追加等が説明される。
- JARTIC利用規約は出典・加工表示と第三者権利の利用者確認を要求する。
- 交通情報提供事業者には正確かつ適切な情報提供と交通安全への配慮が求められる。

## 10. テスト観点

### 正常系

- 公開済み説明書、未レビュー、レビュー済み、未取得の証跡状態を区別できる。
- 版、改訂日、作成基準日、公開日、検証日を独立管理できる。
- 位置・方向・対象・期間・例外が揃わない利用をNo-Goにできる。
- 表示用途とルート用途を別承認にできる。

### 異常系

- 説明書が公開済みであることだけで実データ利用をGoにしない。
- 月次データを現在有効・リアルタイムとして表示しない。
- 不明値を通常値へ補完しない。
- 現地標識よりアプリを優先する案内をしない。

### 境界値

- 説明書公開済み・一部レビュー・全体レビュー済みの状態遷移。
- 開始・終了時刻、曜日、祝日、季節条件。
- 点・線・面、片方向・両方向・不明。
- 対象車両・例外車両・対象不明。
- 重複・矛盾・廃止・更新・版変更。
- 再確認期限当日と翌日。

### 回帰

- 出典・加工・鮮度・保持・削除・位置プライバシー要件を弱めない。
- 実データ・非公開証跡を公開Repositoryへ保存しない。
