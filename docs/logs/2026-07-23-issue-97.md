- 商用利用、複製、公衆送信、加工が公開規約で許容される。
- 出典と加工表示、第三者権利確認が必要である。
- 原則月次更新であり、現在の渋滞・事故・閉鎖を示すライブ交通用途ではない。
- 静的・定期更新データの`用途限定候補`とした。

### JARTIC Jシステム / VICS

- 国内の渋滞、事故・工事、所要時間、閉鎖、駐車場等をオンライン提供する。
- 5分更新、一部1分更新、全国提供メニュー、公開費用を確認した。
- VICS符号型はVICSセンターとの技術開示契約が別途必要である。
- 再提供、キャッシュ、加工、帰属、SLA等は公開資料だけで確定できない。
- 国内ライブ交通情報の`優先問い合わせ候補`とした。

### Google Maps Platform

- 交通対応ルート・所要時間の用途を確認した。
- 保存、再共有、再ホスト、派生データ化、非Google地図との併用に制限がある。
- 提供元中立の交通情報データベース用途には使わない。
- Google地図・ルート基盤と一体で検討する`構成依存候補`とした。

### HERE Traffic API

- リアルタイムFlow / Incidentsと日本カバレッジを確認した。
- キャッシュ、リポジトリ構築、複数利用者への使い回しに制限がある。
- 日本向け上流由来、第三者表示、他社地図重畳、加工、再提供等は契約確認が必要である。
- `優先問い合わせ候補`とした。
