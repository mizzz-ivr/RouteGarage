## 主要判断

### テンプレートと今回チェックを分離

標準/個人テンプレートは再利用定義、今回のチェックは実際に確認するスナップショットとして責務を分離する。

テンプレート更新・削除によって既に作成済みのチェックが意図せず変化しないことを不変条件とした。

### 状態名

MVP候補は`UNCHECKED` / `CHECKED`とし、`PASS` / `FAIL` / `SAFE`等の安全・診断を連想する状態名を採用しない。

### 0項目

対象項目0件を100%完了としない。

### 安全保証禁止

全件`CHECKED`でも「安全確認完了」「走行OK」「整備済み」等を表示しない。

### provider非依存

GPS / Weather API / OBD / Notification providerをIssue #150では導入・選定しない。
