# AI Prompt Log: Issue #124 断面交通量情報の項目単位第三者権利調査

## 依頼

PR #123マージ後の次タスクとして、JARTICオープンデータの実データ候補についてファイル・項目単位の第三者権利調査を進める。

## 目的

一般道路の「断面交通量情報」を最初の対象として、公開資料から確認できる範囲で次を整理する。

- 項目群
- 上流提供者・権利者候補
- JARTIC利用規約の適用範囲
- 交通管理リンクとの依存
- 地点位置情報・全国デジタル道路データベースとの依存
- 利用方法別のGo / No-Go
- 追加証跡・問い合わせ論点

## 制約

- 日本語で記録する。
- Phase 1 / Requirements Definitionを維持する。
- JARTIC ZIP / CSVを取得しない。
- 日本交通管理技術協会の概要版・詳細版を取得・購入しない。
- 実データ、位置情報、走行履歴、非公開証跡をRepositoryへ保存しない。
- 外部問い合わせ、許諾申請、契約、APIキー取得を行わない。
- Next.js / Expo / Maps SDK / DB / API / Infraを実装しない。
- 公開資料の事実、推論、未確認事項を分離する。
- 権利帰属・許諾・法務判断を推測で確定しない。
- 実ファイル名・説明書版・原本ハッシュがない状態を`確認済み`にしない。
- 判断不能時はNo-Goとする。
- AI生成物は人間・法務・運用・安全レビュー必須とする。

## 実施内容

1. PR #123のマージを確認した。
2. Issue #124を作成した。
3. `docs/issue-124-section-traffic-rights`ブランチを作成した。
4. JARTIC利用規約から、一般利用許可と第三者権利確認責任を分離した。
5. 日本交通管理技術協会の公開資料から、交通管理リンク、地点位置情報、DRM依存を整理した。
6. 項目群を観測・識別、地域参照、交通管理リンク参照、地点位置派生へ分けた。
7. 利用方法ごとのNo-Goを整理した。
8. プレフライト台帳レコードを作成した。
9. Source of Truth、ログ、handoffを同期する。

## 主要判断

- 断面交通量情報全体は`調査中 / No-Go`。
- 観測・識別項目も項目別権利処理範囲が未確認のためNo-Go。
- 2次メッシュコードも根拠確認前はNo-Go。
- リンク区分、リンク番号、リンク終端距離、リンクバージョンは交通管理リンクとの関係を解消するまでNo-Go。
- 地点位置のPDF、緯度経度、シェープファイルは別提供・別権利確認が必要でNo-Go。
- 地図表示、履歴公開、エクスポート、Google Maps DatasetsアップロードはNo-Go。
- リンク項目除外後の集計は将来の条件付き候補だが、現在の許可ではない。
