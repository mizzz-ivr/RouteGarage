# 00 Project Overview

## プロダクト概要
RouteGarageは、ドライブ体験の「移動」「記録」「共有」「管理」を統合する日本向けプロダクトです。

## 背景
既存サービスは、ナビ・SNS・記録・車両管理が分断され、車ユーザーは複数アプリを行き来する負担が大きい課題があります。

## 目的
- ドライブ体験を一連の流れで支援する
- 走行記録とスポット共有を両立する
- 安全性とプライバシーに配慮したコミュニティ基盤を提供する

## 想定ユーザー
- 20代〜50代のドライブ愛好者
- 週末旅行・長距離ドライブ利用者
- 愛車管理やカスタム履歴を残したいユーザー

## 初回リリース方針
- 高リスク機能を最小化し、基本価値の検証を優先
- 情報精度が要件となる機能は「参照情報」である旨を明示
- 位置情報公開は保守的デフォルト（非公開寄り）を採用

## MVP方針
MVPは範囲が広いため、以下の優先順位で段階導入する。
1. 走行記録（非公開前提）
2. スポット閲覧・保存
3. 最小限の共有機能（安全制御付き）
4. 拡張機能（交通情報、オービス、コミュニティ強化）

## 主要リスク
- 走行中操作が事故リスクを増やす可能性
- 位置情報から自宅・生活圏が推測されるプライバシーリスク
- 交通情報・事故情報・PA閉鎖情報の遅延/誤りによる誤認リスク
- オービス情報の法令・規約上の取り扱いリスク
- 投稿内容が違法改造を助長するリスク
