# RouteGarage MVP 画面一覧（Issue #10）

## 1. 前提

- 本資料は `docs/requirements/mvp-requirements.md` を正本として、初回リリース（Web MVP）に必要な画面責務を定義する。
- 技術スタック（Next.js/TypeScript含む）、DB、API、認証方式、インフラは未確定のため、本資料では断定しない。
- 走行中操作を助長しないことを最上位制約とし、停車中利用を前提に導線を設計する。

## 3. 画面責務の補足

- SCR-05/06/15では「参考情報」であることを常時表示し、運転判断の唯一根拠にしない注意喚起を維持する。
- SCR-09/11/19では公開範囲・EXIF・生活圏推定リスクの説明を必須項目として扱う。
- SCR-17/18/20は商用運用導線（通報・問い合わせ・規約）としてMVP必須に位置づける。
