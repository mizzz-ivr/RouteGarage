# ドライブコレクション 画面要件拡張

## 1. 対象

Issue #132で追加するドライブコレクション・訪問進捗機能の画面責務を定義する。

本資料は既存`docs/screen-design/screen-list.md`と`docs/screen-design/screen-flow.md`へ統合する前のレビュー用差分である。

## 2. 追加画面

### SCR-28 ドライブコレクション一覧

主な利用者:

- ログインユーザー

目的:

- テーマから次のドライブ候補を発見する。

主な表示:

- コレクションタイトル
- テーマ
- 対象エリア
- 対象スポット数
- 保存状態
- 本人の現在版進捗
- `REVIEW_REQUIRED` / `STOPPED`等の状態表示
- 季節・再確認注意

主要操作:

- テーマ絞り込み
- エリア絞り込み
- 保存・解除
- SCR-29へ遷移

制約:

- `PUBLISHED`以外を通常一覧へ掲載しない。
- 進捗は本人だけに表示する。
- ランキング、最速、他ユーザー達成数による煽り表示を行わない。

### SCR-29 ドライブコレクション詳細

主な利用者:

- ログインユーザー

目的:

- テーマ、対象スポット、注意事項、自分の進捗を確認し、出発前計画または走行後記録へ接続する。

主な表示:

- タイトル
- 概要
- テーマ
- 対象エリア
- カバー画像（権利確認済みの場合のみ）
- 注意事項
- content_revision
- reviewed_at
- 必要に応じてrecheck_due_at
- スポット一覧
- 地点ごとの`NOT_VISITED` / `VISITED` / `UNAVAILABLE`
- 訪問数 / 対象数 / 進捗率
- 現在版達成状態

主要操作:

- 保存・解除
- スポット詳細へ
- 行きたいへ追加
- ドライブプランへ追加
- 訪問済み登録・取消
- SCR-30へ遷移

制約:

- コレクションの表示順を推奨ルートとして表示しない。
- 通行可能・安全・営業中を保証しない。
- 停止済みスポットの本文・画像・正確位置を表示しない。
- 訪問登録は停車中または走行後に行う注意を表示する。

### SCR-30 自分のコレクション進捗

主な利用者:

- ログインユーザー本人

目的:

- 保存中・進行中・達成済みコレクションを個人記録として見返す。

主な表示:

- 保存コレクション一覧
- `NOT_STARTED` / `IN_PROGRESS` / `COMPLETED`
- 現在版進捗
- 旧版達成記録
- 訪問日時（入力している場合、本人のみ）
- 個人メモ
- 走行記録参照
- 記念バッジ候補

主要操作:

- 訪問記録編集・取消
- 走行記録参照追加・解除
- コレクション詳細へ
- 保存解除

制約:

- 他ユーザーへ訪問履歴を公開しない。
- 正確な移動順・現在地・速度を表示しない。
- 達成記録を競争ランキングへ接続しない。

## 3. 既存画面の更新候補

### SCR-05 ホーム

追加候補:

- おすすめテーマへの導線
- 保存中コレクションの進捗
- 次に巡る候補

制約:

- 「今すぐ行く」「残り○時間」等、急行を促す表現を避ける。

### SCR-06 地図・スポット一覧

追加候補:

- コレクション対象スポットの識別
- SCR-28へのテーマ探索導線

ただし大量バッジ表示で地図の安全注意・視認性を損なわない。

### SCR-08 / SCR-10 走行記録

追加候補:

- 本人の走行記録を訪問記録へ任意参照する導線

位置一致だけで自動訪問済みにしない。

### SCR-12 スポット詳細

追加候補:

- 当該スポットが含まれる公開コレクションへのリンク
- 訪問済み登録候補

停止済みコレクションや非公開進捗を表示しない。

### SCR-21 行きたいスポット一覧

追加候補:

- コレクションから追加されたスポットの識別候補

コレクション保存と行きたい保存の責務は分離する。

### SCR-23 ドライブプラン作成/編集

追加候補:

- コレクション詳細から対象スポットを追加

コレクション順を自動的に最適ルートとして採用しない。

### SCR-19 設定

将来候補:

- 達成記録公開の既定値

内部βでは非公開固定を推奨する。

## 4. 全体導線差分

```text
[SCR-05 ホーム]
  ├─> [SCR-28 ドライブコレクション一覧]
  │      └─> [SCR-29 ドライブコレクション詳細]
  │              ├─> [SCR-12 スポット詳細]
  │              ├─> [SCR-21 行きたいスポット一覧]
  │              ├─> [SCR-23 ドライブプラン作成/編集]
  │              └─> [SCR-30 自分のコレクション進捗]
  └─> [SCR-30 自分のコレクション進捗]
             ├─> [SCR-29 ドライブコレクション詳細]
             └─> [SCR-10 走行記録詳細]
```

## 5. 発見導線

1. SCR-05またはSCR-06からSCR-28へ進む。
2. テーマ・エリアで絞り込む。
3. SCR-29で概要・スポット・注意事項を確認する。
4. 気になる場合はコレクションを保存する。
5. 個別スポットを行きたいまたはプランへ追加する。

## 6. 計画導線

1. SCR-29で未訪問スポットを確認する。
2. スポット詳細を確認する。
3. 必要なスポットだけSCR-23へ追加する。
4. 地点順はユーザー自身で設定する。
5. 既存の安全・交通情報注意を確認する。

コレクション順は走行順でも推奨経路でもない。

## 7. 走行後進捗導線

1. 停車後または走行後にSCR-29またはSCR-30を開く。
2. 対象スポットを訪問済みとして登録する。
3. 必要に応じて訪問日時・個人メモを追加する。
4. 必要に応じてSCR-10の本人走行記録を参照する。
5. 進捗を再計算する。
6. 現在版を全件達成した場合、達成記録生成候補へ進む。

## 8. コレクション版更新時

1. 新しい`content_revision`を公開する。
2. SCR-29では現在版を表示する。
3. SCR-30では旧版達成を保持する。
4. 現在版の進捗を再計算する。
5. 削除・停止された元スポット情報を旧版画面へ復元しない。

## 9. 元スポット停止時

1. 元スポット停止を検知する。
2. SCR-28/29で停止済みスポットの本文・画像・正確位置を表示しない。
3. SCR-29/30で該当地点を`UNAVAILABLE`として扱う。
4. 新規訪問登録を止める。
5. コレクションを`REVIEW_REQUIRED`または必要に応じて`STOPPED`とする。
6. 分母変更が必要な場合は新版作成を検討する。

## 10. 操作制約

- 訪問登録・取消・メモ・プラン追加は停車中または走行後に限定する。
- GPS許可を要求する導線を追加しない。
- ランキング・速度・最短時間を表示しない。
- `STOPPED`を一般ユーザー操作で解除しない。
- 非公開進捗をURL直指定で取得できない設計を後続API要件へ引き継ぐ。

## 11. アクセシビリティ

- 進捗は色だけで表現しない。
- `未訪問`、`訪問済み`、`利用不可`を文字でも表示する。
- 進捗率だけでなく訪問数 / 対象数を表示する。
- 状態アイコンには代替テキストを付ける。
- キーボードで一覧・詳細・保存・訪問登録へ到達できることを後続設計で確認する。
