# RouteGarage MVP 画面遷移・主要導線（Issue #10）

## 1. 方針

- 本遷移は要件定義フェーズのレビュー用であり、実装仕様ではない。
- 走行中操作を防ぐため、入力・投稿・プラン編集系導線は「停車中利用前提」の警告表示を含む。
- 交通情報・オービス情報は参考情報として扱い、誤認防止文言を全導線で維持する。
- ドライブプランは運転指示ではなく、出発前に確認する予定表として扱う。

## 3. 主要導線

### 3.1 初回利用導線

1. SCR-01でサービス概要・安全方針を確認。
2. SCR-02で登録、またはSCR-03でログイン。
3. SCR-05で主要機能の制約（停止時利用、参考情報）を再確認。

### 3.2 行きたいスポット保存導線

1. SCR-06または公開投稿からSCR-12を開く。
2. 元スポットが閲覧可能・停止対象外であることを確認する。
3. 「行きたい」に保存する。
4. SCR-21で保存状態・元スポット状態・個人メモを確認する。
5. 必要に応じて新規または既存ドライブプランへ追加する。

### 3.3 ドライブプラン作成導線（停車中・出発前）

1. SCR-05 → SCR-22 → SCR-23で新規プランを作成する。
2. SCR-21の保存済みスポット、SCR-12のスポット、または自由入力地点を追加する。
3. 地点順を手動で並べ、予定日・時刻・滞在予定・メモを入力する。
4. `DRAFT`として保存する。
5. 1件以上の有効地点とタイトルを確認して`CONFIRMED`へ進める。
6. SCR-24で地点状態、安全注意、公開範囲を確認する。

自動ルート最適化、通行可否判定、リアルタイム再探索は行わない。

### 3.4 ドライブプラン公開導線

1. SCR-24で公開操作を開始する。
2. 状態を`PUBLIC_REVIEW_REQUIRED`とする。
3. 生活拠点、正確位置、自由入力地点、個人情報、元スポット状態を確認する。
4. 問題がない場合のみ`PUBLIC`へ遷移する。
5. 停止要因がある場合は`PRIVATE`を維持するか`STOPPED`へ遷移する。

内部βで公開機能を有効化するかは未確定とする。

### 3.5 ツーリング前導線（停車中）

1. SCR-05 → SCR-22 → SCR-24で確定済みプランを確認する。
2. 必要に応じてSCR-06/07で地図・ルート概要を参照する。
3. SCR-15で交通/オービス参考情報を確認する。
4. 最新性・正確性限界と現地情報優先を確認する。
5. 出発後の操作を促さない。

### 3.6 ツーリング後導線

1. SCR-24でプランを`COMPLETED`へ更新する。
2. 「走行記録を作成」からSCR-09へ遷移する。
3. プランのタイトル、予定日、粗いエリア、メモを入力補助として確認する。
4. 計画値と実績値を区別して走行記録を入力する。
5. 公開範囲とプライバシー注意を確認して保存する。
6. SCR-08/10で記録見返し・公開設定を見直す。

### 3.7 投稿/コミュニティ導線

1. SCR-11でスポット投稿を作成（画像・説明入力）。
2. SCR-12/13/14で公開投稿を閲覧。
3. 不適切投稿はSCR-17から通報。

### 3.8 商用運用導線

- 通報: SCR-12/14 → SCR-17
- 問い合わせ: SCR-05 → SCR-18
- 規約確認: SCR-01/19 → SCR-20

## 4. 元スポット状態変化時の導線

### 4.1 非公開・削除・権利停止・安全停止

1. 元スポットの状態変化を検知する。
2. SCR-21で元本文・正確位置・画像を表示しない。
3. SCR-23/24で該当地点を利用不能または再確認必要として表示する。
4. 公開プランは表示停止を先に行う。
5. 所有者へ一般化した理由と必要な操作を表示する。
6. 地点削除・差し替え・プラン非公開化を選択できる候補とする。

### 4.2 更新

- 非公開プランでは更新を通知する候補とする。
- 公開プランでは位置・意味・権利・安全に影響する変更を再レビュー対象とする。
- 元情報を古いスナップショットのまま公開し続けない。

## 5. 画面遷移時の制約ルール

- 投稿・編集・所有者操作画面（SCR-09/11/16/19/23/24）は先頭で「停車中に操作してください」を表示する。
- SCR-24の公開レビュー、非公開化、完了、中止、複製、走行記録作成等の所有者操作は停車中または出発前・走行後の操作に限定する。公開閲覧者の読み取り表示とは責務を分離する。
- 交通/オービス表示画面（SCR-06/07/12/15）は更新時刻と免責文言を固定領域で表示する。
- 公開系操作（SCR-09/10/19/24）は公開範囲確認を必須ステップ化する。
- SCR-24は`PRIVATE`から直接`PUBLIC`へ遷移させず、公開前レビューを経由する。
- SCR-23/24では手入力値と外部計算値の由来を区別する。
- SCR-21/23/24では元スポット停止時に古い本文・正確位置・画像を再表示しない。
- 通報導線（SCR-17）は全公開コンテンツ画面から2クリック以内到達を目標とする（UI配置は後続設計で確定）。

## 6. 後続Issueへ引き継ぐ設計論点

- 行きたいスポット・ドライブプランのデータモデルとAPI境界
- 各画面の情報設計（項目定義、必須/任意、入力検証）
- SCR-24の公開閲覧表示と所有者操作領域の分離
- 地点並び替えの競合制御
- 元スポット停止・削除伝播の詳細設計
- ドライブプラン公開前レビューの具体文言・判定項目
- 走行中抑止UIの具体文言・表示条件
- 公開範囲の既定値と変更時確認フロー
- 画像投稿時のEXIF取り扱いUI
- 通報受付後のモデレーション運用オペレーション
- 監査ログとの接続点（どの画面操作を監査対象にするか）
