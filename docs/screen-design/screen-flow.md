# RouteGarage MVP 画面遷移・主要導線（Issue #10）

## 1. 方針

- 本遷移は要件定義フェーズのレビュー用であり、実装仕様ではない。
- 走行中操作を防ぐため、入力・投稿・プラン編集・ストーリー作成・チェックリスト更新系導線は「停車中利用前提」の警告表示を含む。
- 交通情報・オービス情報は参考情報として扱い、誤認防止文言を全導線で維持する。
- ドライブプランは運転指示ではなく、出発前に確認する予定表として扱う。
- ドライブストーリーは`published_at`から24時間だけ公開し、期限切れと物理削除を分離する。
- ドライブ前チェックリストは準備確認支援であり、全項目確認済みでも安全・整備・法的適合・走行可否を保証しない。

## 3. 主要導線

### 3.1 初回利用導線

1. SCR-01でサービス概要・安全方針を確認。
2. SCR-02で登録、またはSCR-03でログイン。
3. SCR-05で主要機能の制約（停止時利用、参考情報、24時間表示）を再確認。

### 3.2 行きたいスポット保存導線

1. SCR-06または公開投稿からSCR-12を開く。
2. 元スポットが閲覧可能・停止対象外であることを確認する。
3. 「行きたい」に保存する。
4. SCR-21で保存状態・元スポット状態・個人メモを確認する。
5. 必要に応じて新規または既存ドライブプランへ追加する。

### 3.3 ドライブプラン作成導線（停車中・出発前）

1. SCR-05 → SCR-22 → SCR-23で新規プランを作成する。
2. SCR-21の保存済みスポット、SCR-12のスポット、または自由入力地点を追加する。
3. 地点順を手動で並べ、予定日・時刻・滞在予定・メモを入力する。
4. `DRAFT`として保存する。
5. 1件以上の有効地点とタイトルを確認して`CONFIRMED`へ進める。
6. SCR-24で地点状態、安全注意、公開範囲を確認する。

自動ルート最適化、通行可否判定、リアルタイム再探索は行わない。

### 3.4 ドライブプラン公開導線

1. SCR-24で公開操作を開始する。
2. 状態を`PUBLIC_REVIEW_REQUIRED`とする。
3. 生活拠点、正確位置、自由入力地点、個人情報、元スポット状態を確認する。
4. 問題がない場合のみ`PUBLIC`へ遷移する。
5. 停止要因がある場合は`PRIVATE`を維持するか`STOPPED`へ遷移する。

内部βで公開機能を有効化するかは未確定とする。

### 3.5 ツーリング前導線（停車中）

1. SCR-05 → SCR-22 → SCR-24で確定済みプランを確認する。
2. 必要に応じてSCR-06/07で地図・ルート概要を参照する。
3. SCR-15で交通/オービス参考情報を確認する。
4. 最新性・正確性限界と現地情報優先を確認する。
5. 必要に応じてSCR-05 → SCR-39 → SCR-38で出発前の持ち物・準備項目を確認する。
6. 出発後の操作を促さない。

### 3.6 ツーリング後導線

1. SCR-24でプランを`COMPLETED`へ更新する。
2. 「走行記録を作成」からSCR-09へ遷移する。
3. プランのタイトル、予定日、粗いエリア、メモを入力補助として確認する。
4. 計画値と実績値を区別して走行記録を入力する。
5. 公開範囲とプライバシー注意を確認して保存する。
6. SCR-08/10で記録見返し・公開設定を見直す。
7. 必要に応じて公開中の本人走行記録を参照するストーリーをSCR-25で作成する。

### 3.7 ドライブストーリー作成・公開導線（停車中・走行後）

1. SCR-05、SCR-10、SCR-12、SCR-16またはSCR-27からSCR-25を開く。
2. 「停車中または走行後に操作してください」を確認する。
3. JPEG / PNG画像、短文、任意の参照リンク、粗いエリアを入力する。
4. 画像の実体形式・容量・デコード可否を検査する。
5. EXIF除去結果を確認する。除去失敗時は公開へ進めない。
6. 人物、ナンバープレート、表札、生活拠点、反射物等の映り込みを確認する。
7. 公開範囲を`PRIVATE`から`PUBLIC_REVIEW_REQUIRED`へ変更する。
8. 24時間後に公開表示が終了すること、期限後もスクリーンショット等が残り得ることを確認する。
9. 問題がない場合のみ`PUBLISHED`かつ`PUBLIC`へ遷移し、`expires_at = published_at + 24 hours`を設定する。
10. 問題がある場合は`PRIVATE`を維持するか下書きを破棄する。

現在地の自動取得、正確座標の保存、走行中撮影・自動投稿は行わない。

### 3.8 ドライブストーリー閲覧・通報導線

1. SCR-05またはSCR-13からSCR-26を開く。
2. 閲覧時に`STOPPED`、`DELETED`、`EXPIRED`、`expires_at`、公開状態、認可を確認する。
3. 公開可能な場合だけ画像・短文・粗いエリア・参照リンクを表示する。
4. 前・次のストーリーへ移動する。
5. 不適切な場合は2操作以内でSCR-17へ遷移する。
6. 必要に応じて当該ストーリーを個別非表示にする。
7. 投稿者単位のストーリーミュートを提供するかは内部β前に確定する。

返信、DM、コメント、リアクション、個別閲覧者一覧は提供しない。

### 3.9 ドライブストーリー管理導線

1. SCR-05 → SCR-27で本人の下書き・公開中・期限切れ候補を確認する。
2. 下書きはSCR-25で編集・公開確認する。
3. 公開中ストーリーは非公開化または削除要求できる。
4. 非公開化・削除要求時は公開表示を先に停止する。
5. `STOPPED`は投稿者が解除できない。
6. 期限切れと物理削除完了を同じ表示にしない。
7. 投稿者向け期限切れ履歴・アーカイブの有無は未確定とする。

### 3.10 投稿/コミュニティ導線

1. SCR-11でスポット投稿を作成（画像・説明入力）。
2. SCR-12/13/14で通常の公開投稿を閲覧する。
3. SCR-13/26で24時間限定ストーリーを通常投稿と区別して閲覧する。
4. 不適切投稿・ストーリーはSCR-17から通報する。

### 3.11 商用運用導線

- 通報: SCR-12/14/26 → SCR-17
- 問い合わせ: SCR-05 → SCR-18
- 規約確認: SCR-01/19 → SCR-20

### 3.12 ドライブ前チェック導線（出発前・停車中）

1. SCR-05からSCR-39を開く。
2. RouteGarage標準テンプレートまたは本人の個人テンプレートを選択する。
3. 選択したテンプレートからSCR-38の「今回のチェック」を作成する。
4. 必要に応じて今回だけの項目を追加、不要項目を除外する。
5. 項目を確認した場合だけ`UNCHECKED`から`CHECKED`へ切り替える。
6. SCR-38では確認済み件数 / 対象件数を表示する。対象0件を100%完了扱いしない。
7. 全件`CHECKED`でも「安全確認完了」「整備済み」「走行可能」等の保証表現へ遷移しない。
8. 必要に応じてSCR-40で本人の個人テンプレートを管理し、SCR-39へ戻る。
9. 出発後のチェック・編集・リセットを促さない。

標準テンプレート更新や個人テンプレート編集は、作成済みの今回チェックへ暗黙反映しない。チェック履歴保存、一括チェック/解除、最近使ったテンプレート表示等は未確定のため本導線では断定しない。

## 4. 元コンテンツ・ストーリー状態変化時の導線

### 4.1 元スポットの非公開・削除・権利停止・安全停止

1. 元スポットの状態変化を検知する。
2. SCR-21で元本文・正確位置・画像を表示しない。
3. SCR-23/24で該当地点を利用不能または再確認必要として表示する。
4. 公開プランは表示停止を先に行う。
5. 元スポットを参照する公開ストーリーは参照リンク・名称・サムネイル・位置表示を停止する。
6. ストーリー独自の画像・短文が公開可能か再判定する。
7. 独立して公開できない場合はストーリーを`STOPPED`とする。
8. 所有者へ一般化した理由と必要な操作を表示する。

### 4.2 走行記録・車両プロフィール参照停止

- 非公開・削除・停止時はストーリー上の参照を解除する。
- 本人のコンテンツであっても非公開状態をストーリー経由で公開しない。
- 参照解除後もストーリー画像・短文が独立して公開可能か再判定する。

### 4.3 ストーリー期限到達

1. UTC基準で`now >= expires_at`を確認する。
2. ライフサイクルを`EXPIRED`として扱う。
3. SCR-05/13/26、プロフィール、直接URL、画像配信から一般閲覧を停止する。
4. 未解決通報は維持する。
5. 期限切れを物理削除完了として表示しない。
6. 通常保持・削除SLAに従う後続処理へ引き渡す。

### 4.4 投稿者削除・管理者停止・期限到達の競合

優先順位は次のとおりとする。

1. 管理者・権利・安全・プライバシーによる`STOPPED`
2. 投稿者削除要求`DELETED`
3. 期限到達`EXPIRED`
4. 通常公開状態

いずれの場合も公開停止を物理削除より先に行う。

## 5. 画面遷移時の制約ルール

- 投稿・編集・所有者操作画面（SCR-09/11/16/19/23/24/25/27/38/40）は先頭で「停車中または走行後に操作してください」を表示する。
- SCR-24の公開レビュー、非公開化、完了、中止、複製、走行記録作成等の所有者操作は停車中または出発前・走行後の操作に限定する。公開閲覧者の読み取り表示とは責務を分離する。
- SCR-25はEXIF除去失敗、入力検査失敗、公開前確認未完了の場合に`PUBLIC`へ進めない。
- SCR-25は`PRIVATE`から直接`PUBLIC`へ遷移させず、`PUBLIC_REVIEW_REQUIRED`を経由する。
- SCR-26は`STOPPED`、`DELETED`、`EXPIRED`、`now >= expires_at`、認可不成立の場合に画像・短文を表示しない。
- SCR-26は閲覧用画面であり、返信・DM・コメント・リアクション・閲覧者一覧を持たない。
- SCR-27は`STOPPED`を投稿者操作で解除できない。
- ストーリーの期限判定はバッチだけに依存せず閲覧要求時にも実施する。
- 交通/オービス表示画面（SCR-06/07/12/15）は更新時刻と免責文言を固定領域で表示する。
- 公開系操作（SCR-09/10/19/24/25/27）は公開範囲確認を必須ステップ化する。
- SCR-24は`PRIVATE`から直接`PUBLIC`へ遷移させず、公開前レビューを経由する。
- SCR-23/24では手入力値と外部計算値の由来を区別する。
- SCR-21/23/24では元スポット停止時に古い本文・正確位置・画像を再表示しない。
- SCR-38は`CHECKED`を安全・整備・法的適合・走行可否へ変換しない。対象0件を100%完了扱いしない。
- SCR-38の今回項目追加/除外・状態変更・リセットを、SCR-39/40の元テンプレートへ暗黙反映しない。
- SCR-39/40では個人テンプレートを本人以外へ表示・操作させない。
- SCR-38/40のユーザー入力は任意HTMLとして扱わず、表示時に安全な文字列境界を維持する。
- 通報導線（SCR-17）は全公開コンテンツ画面から2クリック以内到達を目標とする（UI配置は後続設計で確定）。
