# RouteGarage MVP 画面遷移・主要導線（Issue #10）

## 1. 方針

- 本遷移は要件定義フェーズのレビュー用であり、実装仕様ではない。
- 走行中操作を防ぐため、入力・投稿系導線は「停車中利用前提」の警告表示を含む。
- 交通情報・オービス情報は参考情報として扱い、誤認防止文言を全導線で維持する。

## 2. 全体遷移（高レベル）

```text
[SCR-01 ランディング]
  ├─> [SCR-02 ユーザー登録] ─> [SCR-05 ホーム]
  ├─> [SCR-03 ログイン] ─────> [SCR-05 ホーム]
  └─> [SCR-20 規約/プライバシー]

[SCR-05 ホーム]
  ├─> [SCR-06 地図・スポット一覧] ─> [SCR-12 スポット詳細] ─> [SCR-17 通報フォーム]
  │                                └> [SCR-07 ルート閲覧詳細]
  ├─> [SCR-08 走行記録一覧] ─> [SCR-10 走行記録詳細]
  │                         └> [SCR-09 走行記録作成/編集]
  ├─> [SCR-13 コミュニティ投稿一覧] ─> [SCR-14 投稿詳細] ─> [SCR-17 通報フォーム]
  ├─> [SCR-15 交通/オービス参考情報]
  ├─> [SCR-16 ガレージ管理]
  ├─> [SCR-19 設定]
  └─> [SCR-18 問い合わせ]
```

## 3. 主要導線

### 3.1 初回利用導線

1. SCR-01でサービス概要・安全方針を確認。
2. SCR-02で登録、またはSCR-03でログイン。
3. SCR-05で主要機能の制約（停止時利用、参考情報）を再確認。

### 3.2 ツーリング前導線（停車中）

1. SCR-05 → SCR-06でスポット候補を閲覧。
2. 必要に応じてSCR-07でルート概要を確認。
3. SCR-15で交通/オービス参考情報を確認。
4. 「最新性・正確性限界」を確認した上で出発判断（本サービス外の運転判断）。

### 3.3 ツーリング後導線

1. SCR-05 → SCR-09で走行記録を作成。
2. 公開範囲とプライバシー注意を確認して保存。
3. SCR-08/10で記録見返し・公開設定見直し。

### 3.4 投稿/コミュニティ導線

1. SCR-11でスポット投稿を作成（画像・説明入力）。
2. SCR-12/13/14で公開投稿を閲覧。
3. 不適切投稿はSCR-17から通報。

### 3.5 商用運用導線

- 通報: SCR-12/14 → SCR-17
- 問い合わせ: SCR-05 → SCR-18
- 規約確認: SCR-01/19 → SCR-20

## 4. 画面遷移時の制約ルール

- 投稿・編集系画面（SCR-09/11/16/19）は先頭で「停車中に操作してください」を表示。
- 交通/オービス表示画面（SCR-06/07/12/15）は更新時刻と免責文言を固定領域で表示。
- 公開系操作（SCR-09/10/19）は公開範囲確認を必須ステップ化する。
- 通報導線（SCR-17）は全公開コンテンツ画面から2クリック以内到達を目標とする（UI配置は後続設計で確定）。

## 5. 後続Issueへ引き継ぐ設計論点

- 各画面の情報設計（項目定義、必須/任意、入力検証）
- 走行中抑止UIの具体文言・表示条件
- 公開範囲の既定値と変更時確認フロー
- 画像投稿時のEXIF取り扱いUI
- 通報受付後のモデレーション運用オペレーション
- 監査ログとの接続点（どの画面操作を監査対象にするか）
