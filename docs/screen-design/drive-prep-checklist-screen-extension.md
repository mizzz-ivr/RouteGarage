# ドライブ前チェックリスト 画面要件拡張

## 1. 対象

Issue #150で追加するドライブ前チェックリスト・持ち物テンプレート機能の画面責務を定義する。

既存画面IDとの競合を避けるため、以下はcanonical統合前の候補IDとする。

## 2. 追加画面候補

### SCR-38候補 ドライブ前チェックリスト

主な利用者:
- ログインユーザー本人

目的:
- 出発前または停車中に、今回必要な準備項目を短時間で確認する。

主な表示:
- チェックリスト名
- 出発前・停車中利用の注意
- 確認済み件数 / 対象件数
- 項目一覧
- `UNCHECKED` / `CHECKED`の文字表示
- 「確認済みは安全・整備状態を保証しない」補足

主要操作:
- 項目を確認済み/未確認へ切り替え
- 今回だけ項目追加
- 今回だけ項目除外
- 状態リセット
- SCR-39候補へ遷移

制約:
- 0件を100%完了表示しない。
- 全件確認済みでも「走行可能」「安全確認完了」等を表示しない。
- 走行中操作を促さない。
- チェック画面からGPS/Weather/OBD等の権限要求を行わない。

アクセシビリティ:
- checkbox相当の状態を色だけで表現しない。
- キーボードで各項目へ到達できることを後続詳細設計で確認する。
- 状態変更後もフォーカスが不自然に失われないことを確認する。

### SCR-39候補 テンプレート選択

主な利用者:
- ログインユーザー本人

目的:
- 今回の用途に合う標準または個人テンプレートを選択する。

主な表示:
- 標準テンプレート
  - 基本
  - 長距離
  - 夜間
  - 雨天
  - ツーリング/複数台移動
- 個人テンプレート
- テンプレート概要
- 項目数

主要操作:
- テンプレートを選択して今回のチェックを作成
- 標準テンプレートを個人テンプレートへ複製する候補
- SCR-40候補へ遷移

制約:
- 天候や現在地から自動でテンプレートを選択しない。
- 標準テンプレート自体を一般ユーザーが編集しない。
- テンプレート選択を「推奨走行可否」へ接続しない。

### SCR-40候補 個人テンプレート管理

主な利用者:
- ログインユーザー本人

目的:
- 自分専用の再利用可能なチェック項目セットを管理する。

主な表示:
- 個人テンプレート一覧
- テンプレート名
- 項目数
- 項目一覧

主な入力:
- テンプレート名
- 項目名
- 項目順序

主要操作:
- 新規作成
- 編集
- 複製
- 削除
- 項目追加/編集/削除/並び替え

制約:
- 他ユーザーの個人テンプレートを表示・編集しない。
- 個人テンプレートの編集で既に作成済みの今回チェックを暗黙更新しない。
- 任意HTMLを入力・描画する機能を提供しない。

## 3. 既存画面拡張候補

### SCR-05 ホーム

追加候補:
- 「出発前チェック」への導線
- 最後に使った個人テンプレートへの再利用導線候補

制約:
- 「今すぐ出発」等の急行を促す表現を避ける。
- 未完了件数を不安・競争要素として強調しない。

### SCR-23 ドライブプラン作成/編集

将来候補:
- プランから出発前チェックを開く導線

制約:
- プランの地点・予定情報をチェック項目へ自動でコピーする仕様は別要件とする。
- 走行中にプラン/チェックを操作させない。

### SCR-16 ガレージ管理

将来候補:
- 個人テンプレートへの導線

制約:
- Garage整備履歴とチェックリストを同一の整備記録として扱わない。
- チェック済み状態を車両の整備済み状態として保存しない。

## 4. 主要導線

```text
[SCR-05 ホーム]
  └─> [SCR-39 テンプレート選択]
          ├─> [SCR-38 ドライブ前チェックリスト]
          └─> [SCR-40 個人テンプレート管理]
                  └─> [SCR-39 テンプレート選択]
```

## 5. 初回利用導線

1. SCR-05からSCR-39候補を開く。
2. 標準テンプレートの用途と注意事項を確認する。
3. テンプレートを選択する。
4. SCR-38候補で今回のチェックを作成する。
5. 必要に応じて今回だけ項目を追加/除外する。
6. 出発前または停車中に項目を確認する。

## 6. 再利用導線

1. SCR-39候補で個人テンプレートを選ぶ。
2. テンプレート定義から今回のチェックを作成する。
3. 既存テンプレートの後続編集が今回のチェックへ暗黙反映されないことを維持する。

## 7. リセット導線

1. SCR-38候補でリセット操作を開始する。
2. リセット対象が「今回のチェック状態」であり、テンプレート定義ではないことを明示する。
3. 実行後、対象項目を`UNCHECKED`へ戻す。
4. 元テンプレート内容は変更しない。

## 8. エラー/空状態

### テンプレート0件

- 標準テンプレート取得失敗時は推測項目を自動生成しない。
- 個人テンプレートが0件の場合は新規作成導線を表示する。

### 今回の項目0件

表示候補:
`確認する項目がありません。テンプレートを選ぶか、自分の項目を追加できます。`

0件を完了扱いしない。

### 保存失敗

- 保存失敗時に確認済み表示を確定済みと誤認させない。
- 再試行可能な場合のみ再試行導線を提供する。
- 詳細な内部例外や認可情報をユーザーへ露出しない。

## 9. アクセシビリティ/レスポンシブ

- 320px幅でもチェック本文・注意表示・主要操作を欠落させない。
- checkbox相当の状態はテキスト/アクセシブルネームでも判別可能にする。
- タップ領域の具体寸法は詳細設計で確定する。
- reduced motion設定を尊重する。
- エラー・状態変化を色だけで表現しない。

## 10. 未確定事項

- 項目カテゴリの具体UI
- 一括チェック/一括解除を提供するか
- 削除確認ダイアログの方式
- 標準テンプレート新版の通知方法

未確定事項は後続設計で確定し、実装で推測補完しない。
