# ドライブ振り返り・統計ダッシュボード 画面拡張（Issue #141）

## 1. 目的

Issue #141の要件を画面責務へ落とし込み、既存`screen-list.md`を直接大規模変更せずレビュー可能なdeltaとして定義する。

## 2. 採番

Issue #132でSCR-28〜30候補、Issue #138でSCR-31〜34候補を使用しているため、本Issueではレビュー上の候補としてSCR-35〜37を使用する。

正本統合時に採番競合を再確認する。

## 3. SCR-35候補: ドライブ振り返りダッシュボード

### 目的

本人が最近のドライブ活動を期間単位で振り返り、詳細へ移動できる起点を提供する。

### 主な表示

- 期間選択
- ドライブ回数
- 合計走行距離
- 平均走行距離
- 最長ドライブ距離
- 記録のある日数
- 利用車両数
- 月別推移
- 車両別サマリー
- 最近の走行記録
- 訪問/コレクション振り返り

### 状態表示

- 対象データあり
- 対象0件
- 距離未入力を含む
- 距離系指標算出不能
- 一部参照先停止

0・未入力・算出不能を同じ`0`で表示しない。

### 主要アクション

- 期間変更
- 月別詳細へ
- 車両別詳細へ
- 走行記録詳細へ
- 行きたいスポットへ
- 保存済みコレクションへ

### 禁止

- 他ユーザー統計閲覧
- 速度ランキング
- 最速/最短時間
- ストリーク
- 正確頻出地点
- 「もっと走ろう」等の走行量評価

### セキュリティ/プライバシー

- 本人限定
- 公開プロフィールへ埋め込まない
- client stateへ他人の統計をprefetchしない
- 停止スポットの本文/画像/正確位置を残さない

## 4. SCR-36候補: 月別ドライブ振り返り

### 目的

選択月の走行実績と関連記録を、日別/記録別に振り返る。

### 主な表示

- 対象年月
- ドライブ回数
- 合計走行距離
- 平均走行距離
- 記録のある日数
- 対象月の走行記録一覧
- 距離未入力記録の存在
- 訪問登録候補
- コレクション達成候補

### 主要アクション

- 前月/翌月
- 走行記録詳細
- 訪問/コレクション詳細
- ダッシュボードへ戻る

### 境界

- 対象0件月
- 月初/月末
- 年跨ぎ
- 距離あり/なし混在

0件月をグラフ上で0として描くかは正本統合前に人間判断する。

## 5. SCR-37候補: 車両別ドライブ振り返り

### 目的

本人所有/管理車両について、走行記録由来の利用傾向を振り返る。

### 主な表示

- 車両表示名
- 対象期間
- ドライブ回数
- 合計走行距離
- 平均走行距離候補
- 最終利用日候補
- 月別推移
- 最近の走行記録

### 表示してはならないもの

Issue #138のGarage履歴非公開境界を継承し、以下を自動統合しない。

- 整備費用
- 給油履歴
- 燃費
- 次回メンテナンス目安
- 店舗名/個人メモ

将来統合する場合は別要件で認可・表示範囲を再レビューする。

### 車両停止/削除

- アーカイブ時は後続設計の表示名ルールに従う。
- 削除済みプロフィール本文を復活させない。
- 非公開Garage履歴を復活させない。
- 車両参照なしの記録を別車両へ推測配分しない。

## 6. ホーム画面への導線delta

既存SCR-05ホームへ以下の追加候補を持つ。

- 「今月の振り返り」カード
- ドライブ回数
- 合計距離（算出可能な場合のみ）
- SCR-35への導線

ホームカード自体も本人限定データとして扱い、公開画面へ使わない。

## 7. 空状態

### 走行記録0件

推奨コピー候補:

- 「この期間のドライブ記録はありません」
- 「走行後に記録を残すと、ここで振り返れます」

禁止:

- 「今月は走行不足です」
- 「もっと走りましょう」

### 距離未入力

- 回数は表示可能
- 距離系カードは「距離データなし」等、0kmとは異なる表現にする

## 8. エラー状態

- 集計取得失敗
- 一部参照先取得失敗
- 認可失敗
- 期間条件不正

集計取得失敗時に前回値を「最新値」のように表示し続けない。

## 9. アクセシビリティ

- グラフだけで情報を伝えない。
- 数値/表/テキストでも同内容へアクセスできること。
- 色だけで0/欠損/算出不能を区別しない。
- 期間切替はkeyboard操作可能とする。

## 10. テスト観点

### 正常

- 期間サマリー表示
- 月別遷移
- 車両別遷移
- 最近の記録詳細遷移

### 異常

- 非所有ユーザーURL直指定
- 集計API失敗候補
- 停止スポット参照
- 削除車両参照

### 境界

- 0件
- 0km
- 距離未入力
- 月跨ぎ/年跨ぎ
- 1車両/複数車両

### 回帰

- SCR-05ホーム
- SCR-08〜10走行記録
- SCR-16 Garage
- SCR-28〜30コレクション候補
- SCR-31〜34 Garage履歴候補
