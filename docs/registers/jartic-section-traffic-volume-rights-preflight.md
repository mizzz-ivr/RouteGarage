## 1. 目的

JARTICが公開する一般道路の「断面交通量情報」について、公開資料だけで確認できる範囲を用いて、項目群ごとの上流由来、第三者権利候補、利用境界、追加確認事項を整理する。

本書は、実ファイル・説明書版・原本ハッシュ・都道府県・対象年月が未確定の状態で公開Goを出すものではない。

次の誤判断を防ぐことを主目的とする。

- JARTIC利用規約だけで全項目の第三者権利が処理済みと判断する
- リンク番号・リンクバージョンを単なる数値として権利確認対象外にする
- JARTICの断面交通量CSVだけで計測地点をGoogle Map等へ表示できると判断する
- 日本交通管理技術協会が提供する位置情報・地図・シェープファイルを別用途へ転用できると判断する
- 権利未確認のリンク項目だけを除外すれば、残りの数値を直ちに公開できると判断する

## 3. 公開資料から確認できた事実

### 3.1 JARTIC公開ページ

2026-08-04確認時、公開ページでは一般道路の「断面交通量情報」について次が案内されていた。

- 各都道府県警察が車両感知器等の計測機器で収集した情報である
- 都道府県・北海道方面ごとのファイルが提供される
- リンク番号の詳細および最新情報は日本交通管理技術協会のページを参照する
- 原則として毎月月初に更新される
- 更新前の情報は取得できなくなる
- 作業状況により更新が遅れる場合がある
- 説明書を読むよう明記されている

確認時の公開ページ表示は「2026年05月分」「更新日 2026年07月01日」であった。

この表示は、データが現在時点の交通量、現在有効な計測地点、リアルタイム情報であることを意味しない。

### 3.2 JARTIC利用規約

利用規約では、公開データについて次が定められている。

- 複製、公衆送信、翻訳・変形等の翻案、商用利用が可能
- 出典表示が必要
- 編集・加工した場合は加工の事実を表示する
- 加工後データをJARTIC、国、府省等が作成したように表示してはならない
- 第三者が著作権その他の権利を有する場合がある
- 権利処理済みと明示されていない第三者権利は、利用者責任で確認・許諾取得が必要
- 第三者権利部分が明確に特定されていない場合がある
- データは予告なく変更、移転、削除される場合がある
- 規約は変更される場合がある
- CC BY 4.0と互換性がある

利用規約は、断面交通量情報の全項目について第三者権利処理済みと保証していない。

### 3.3 日本交通管理技術協会の公開資料

公開ページでは次が説明されている。

- 断面交通量は全国の都道府県警察が収集し、警察庁が取りまとめ、JARTICが提供する
- JARTICの断面交通量情報では、計測地点位置を「リンク番号」と「リンク終端からの距離」で表す
- このリンクは、日本交通管理技術協会が著作権を持つ「交通管理リンク」である
- 日本交通管理技術協会は交通管理リンクデータベースを使い、計測地点位置を地図・緯度経度として提供する
- 位置情報提供は一般財団法人日本デジタル道路地図協会との協同事業である
- 概要版は交通管理リンクと全国デジタル道路データベースを使用したPDF地図である
- 概要版は、JARTIC断面交通量情報の計測地点位置を特定する目的以外に使用できないとされる
- 詳細版AはPDF地図と緯度経度CSVを有料提供する
- 詳細版Bは詳細版Aに加えてシェープファイルを有料提供する

公開ページの参考表では、断面交通量情報の項目として次が示されている。

1. 時刻
2. 情報源コード
3. 計測地点番号
4. 計測地点の名称に相当する項目
5. 2次メッシュコード
6. リンク区分
7. リンク番号
8. 断面交通量
9. リンク終端からの距離
10. リンクバージョン

公開ページの参考表ではNo.4の項目名が「計測地点番号」と表示される一方、内容説明は名称を示している。正式な項目名はJARTIC説明書で再確認する必要がある。

## 4. 上流由来・権利候補

### 4.1 関係主体

| 主体 | 公開資料から確認できる役割 | 現時点の扱い |
| --- | --- | --- |
| 各都道府県警察 | 車両感知器等で断面交通量を収集 | 上流提供者候補。項目別権利・提供条件は未確認 |
| 警察庁 | 都道府県警察の情報を取りまとめる | 上流提供者候補。項目別権利処理範囲は未確認 |
| JARTIC | 都道府県・方面別の断面交通量情報を公開 | 利用規約適用主体。第三者権利処理を一括保証しない |
| 日本交通管理技術協会 | 交通管理リンクDBを作成・管理し、リンクの著作権を持つと説明 | リンク参照項目・位置特定の権利者候補 |
| 日本デジタル道路地図協会 | 全国デジタル道路データベースを作成・管理 | PDF地図・位置情報提供に関係する権利者候補 |

### 4.2 権利判定の基本方針

- `数値である`ことだけで第三者権利確認を省略しない
- 個々の値が著作物でない可能性と、データベース・編集体系・識別体系の権利を分離して確認する
- JARTICから取得できることと、別サービスの位置データへ変換・結合・再配布できることを分離する
- 権利処理済み範囲が明示されていない場合は`不明 / No-Go`とする
- 実ファイル・説明書・規約版・ハッシュを確認するまで、項目名や意味を断定しない

## 5. 項目群別の予備判定

### 5.1 観測・識別項目

対象候補:

- 時刻
- 情報源コード
- 計測地点番号
- 計測地点名称相当
- 断面交通量

| 観点 | 予備判定 |
| --- | --- |
| 上流由来 | 都道府県警察で収集し、警察庁が取りまとめ、JARTICが公開すると説明される |
| 第三者権利 | 項目別の権利処理済み範囲は公開資料だけでは確認できない |
| 複製・保存 | 未確認。JARTIC規約上の一般許可だけで項目別Goにしない |
| 集計・加工 | 将来の条件付き候補だが、実ファイル・説明書・部分利用可否の確認前はNo-Go |
| 数値表示 | 計測地点の識別・鮮度・安全表示が成立するか未確認のためNo-Go |
| 履歴公開 | 履歴保存許可、対象月、版、停止・削除対応が未確認のためNo-Go |

**現在状態: `調査中 / No-Go`**

### 5.2 地域参照項目

対象候補:

- 2次メッシュコード

| 観点 | 予備判定 |
| --- | --- |
| 上流由来 | 公開資料では標準地域メッシュに関するコードと説明される |
| 権利根拠 | 本調査対象資料だけでは、コード体系・値・利用条件の根拠を確定できない |
| 集約利用 | 2次メッシュ集約により位置精度を下げられる可能性はあるが、権利・安全・再識別評価が未実施 |
| 公開 | 説明書・コード体系・集約結果の意味を確認するまでNo-Go |

**現在状態: `未確認 / No-Go`**

標準規格であることや一般利用されていることを理由に、自動的に権利確認済みとしない。

### 5.3 交通管理リンク参照項目

対象候補:

- リンク区分
- リンク番号
- リンク終端からの距離
- リンクバージョン

| 観点 | 予備判定 |
| --- | --- |
| 上流由来 | 日本交通管理技術協会が作成・管理し、著作権を持つと説明する交通管理リンクDBとの関係が明示される |
| リンク番号 | 交通管理リンクを識別する値であり、単なる無関係な数値として扱わない |
| リンク終端距離 | 交通管理リンクの形状・方向・終端定義がなければ位置を解釈できない |
| リンクバージョン | 同協会のリンクDBの版管理と関係すると考えられる。正式条件は未確認 |
| 内部結合キー利用 | 非表示でも利用行為であるため、権利確認なしに許可扱いしない |
| 保存・加工・公開・エクスポート | 追加許諾・利用条件の確認前はNo-Go |

**現在状態: `第三者権利ありの可能性が高い / No-Go`**

公開資料は交通管理リンクDBの権利関係を示すが、JARTIC CSV内の各リンク参照値について、どの利用方法まで権利処理済みかは明示していない。

- 詳細版Bのシェープファイル

| 観点 | 予備判定 |
| --- | --- |
| 提供主体 | 日本交通管理技術協会。日本デジタル道路地図協会との協同事業 |
| 提供条件 | 概要版は目的限定。詳細版は有料提供 |
| 取得 | 本Issueでは行わない |
| RouteGarage地図表示 | 購入条件・利用規約・保存・公衆送信・再配布・商用利用の確認前はNo-Go |
| Google Maps重畳 | 元データ側とGoogle側の双方の条件確認前はNo-Go |

| Google Maps Datasets | アップロード・保持・削除条件が未確認のためNo-Go |

**現在状態: `別契約・別権利確認必要 / No-Go`**

## 7. 部分利用・項目除外の境界

### 7.1 除外だけではGoにならない

リンク区分、リンク番号、リンク終端距離、リンクバージョンを削除した場合でも、次が未確認である。

- 計測地点番号だけで地点・施設・警察管理情報を推定できないか
- 計測地点番号と時刻・交通量の組合せを公開してよいか
- 計測地点名称相当項目に位置・道路・施設情報が含まれるか
- 2次メッシュコードが公開粒度として安全か
- 数値だけでデータとして意味を維持できるか
- 一部項目だけを利用することが規約・説明書上許容されるか
- 加工後の出典・加工表示をどのように行うか

### 7.2 部分利用の将来Go条件

次をすべて満たす場合だけ、リンク参照項目を除外した数値集計を条件付き候補として再評価する。

1. 実ファイル名、対象年月、地域、ハッシュ、説明書版を台帳登録する
2. 項目定義と必須・任意・欠損条件を確認する
3. 上流提供者と第三者権利処理範囲を項目別に確認する
4. リンク参照値・位置派生値が出力、ログ、キャッシュ、バックアップに残らないことを検証する
5. 計測地点番号・名称・メッシュから位置を再推定できないことを評価する
6. 集約後データの意味・誤解・安全影響を評価する
7. 出典、加工表示、対象年月、非リアルタイム注意を確定する
8. 法務、運用、安全、セキュリティ、プロジェクト責任者が承認する

## 8. 位置表示のNo-Go条件

次のいずれかがある場合、計測地点・リンク・交通量の地図表示をNo-Goとする。

- 交通管理リンクの利用条件を確認できない
- リンク番号・リンク終端距離・リンクバージョンの利用許諾範囲が不明
- 日本交通管理技術協会の位置情報提供条件を確認できない
- 日本デジタル道路地図協会の権利・帰属・利用条件を確認できない
- 購入データの保存・公衆送信・二次利用・再配布条件が不明
- Google Maps等への重畳が双方の条件を満たすか確認できない
- リンク版と計測データ版の整合を確認できない
- 位置変換の真正性・誤差・欠損・方向を検証できない
- 更新遅延・旧版・廃止地点を現在位置として表示する可能性がある
- 停止・削除・再取得拒否を全保存先へ伝播できない

- 概要版の完全な利用条件
- 詳細版A・Bの購入規約・ライセンス
- 保存期間、利用者・端末・組織範囲
- 商用利用、公衆送信、Web・アプリ表示の可否
- 加工・座標変換・派生データ作成の可否
- 再配布・エクスポート・第三者提供の可否
- Google Maps等の別地図上への表示可否
- 出典・帰属表示
- 契約終了・更新・削除義務
- リンク番号・リンク版をJARTIC CSVから利用する場合の条件

### 9.3 日本デジタル道路地図協会側

- 全国デジタル道路データベースの関与範囲
- 概要版・詳細版の地図・位置データへ適用される権利
- RouteGarageでの地図表示・派生・再配布条件
- 必須帰属・表示義務

外部問い合わせ・購入は別Issueで承認を得てから行う。

## 12. テスト・レビュー観点

### 正常系

- 各項目群から上流提供者・権利者候補・根拠資料を追跡できる
- リンク参照項目を含む利用をNo-Goにできる
- 実ファイル・ハッシュなしで`確認済み`へ昇格しない
- 条件付き候補と現在の許可を区別できる

### 異常系

- JARTIC利用規約だけで第三者権利処理済みと判断する
- リンク番号を内部利用なら自由と判断する
- 有料位置情報を購入せず独自緯度経度化する
- 概要版地図をRouteGarageの一般地図レイヤーへ転用する
- リンク項目を除外しただけで残り項目を公開する
- 実データ・非公開証跡を公開Repositoryへ保存する

### 境界値

- リンク番号を表示せず内部結合だけに利用する
- リンク終端距離だけを保存する
- 計測地点番号と断面交通量だけを表示する
- 2次メッシュ単位へ集約する
- 同一地点を異なるリンクバージョンへ対応付ける
- 対象月は同じだが原本ファイルが差し替わる
- 再確認期限当日・期限超過・公開資料変更検知時

### 回帰

- 判断不能時No-Goを維持する
- 出典・加工表示を維持する
- 月次データをリアルタイム情報として扱わない
- 保持上限・削除SLA・全系譜削除要件を維持する
- 生活拠点・外部キャプチャ保護要件を弱めない
- Next.js / Expo / Maps SDK実装へ進まない
