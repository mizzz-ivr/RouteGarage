# 交通情報データ提供元への問い合わせ共通前提（Issue #99）

- 対象Issue: https://github.com/mizzz-ivr/RouteGarage/issues/99
- 作成日: 2026-07-23
- 用途: JARTIC Jシステム / VICSおよびHEREへの問い合わせ前提
- 状態: 送信前ドラフト
- AI利用: ChatGPT / Codex支援、人間レビュー必須

## 1. 文書の目的

交通情報データ提供元へ、RouteGarageの想定利用形態と確認したい契約・技術事項を過不足なく説明するための共通前提を定義する。

本書および個別問い合わせ票は、問い合わせ送信、契約締結、採用決定、法的判断を行うものではない。

## 2. RouteGarageの説明

RouteGarageは、ドライブのルート、立ち寄りスポット、走行記録等を管理・共有するサービスを検討しているプロジェクトである。

現在は要件定義フェーズであり、技術スタック、地図基盤、交通情報提供元、API、DB、認証、インフラ、モバイル対応は未確定である。

### 想定する交通情報の利用目的

- 事故、通行止め、工事、渋滞等を参考情報として表示する
- 利用者が走行前または安全な場所へ停車中にルート状況を確認できるようにする
- 取得した情報のみを運転判断の唯一の根拠にしない旨を表示する
- 情報源、提供元更新時刻、鮮度、検証状態、遅延・欠落可能性を利用者へ示す
- 規約変更、契約停止、障害、権利不明、安全判断不能時に提供を停止できるようにする

### 利用しない目的

- 走行中の画面注視・タップ操作を促す通知
- 移動式取締り・警察位置のリアルタイム共有
- 取締り地点を避けるルート提案
- 正確なオービス地点だけで減速することを促す表示
- 危険運転、速度超過、違法改造、迷惑行為を助長する機能

## 3. 現時点の想定提供形態

以下は問い合わせ用の仮定であり、採用決定ではない。

- Webサービスと将来のモバイルアプリで利用者へ表示する可能性がある
- RouteGarageのサーバーが提供元APIまたは配信システムから情報を取得する可能性がある
- 地図上の表示、一覧表示、ルート計算時の参考情報として利用する可能性がある
- 複数利用者へ同一情報を表示する可能性がある
- 情報源ごとの状態管理、監査、問い合わせ対応のためメタデータを保持する可能性がある
- キャッシュや履歴保存は契約上許可された場合に限り検討する
- 他社地図との重畳は、提供元と地図提供元の双方から明示的に許可された場合に限る

## 4. 未確定事項

問い合わせ時点で次は未確定である。

- 月間利用者数・同時利用者数
- 対象地域・道路種別・利用エリア数
- 1日・1か月のリクエスト数
- 地図基盤
- Web / iOS / Androidの提供範囲
- 無料・有料プラン
- キャッシュ期間・履歴期間
- 具体的な鮮度閾値
- 表示する情報項目
- 本番開始時期

未確定値を確定済みとして回答欄へ記載してはならない。提供元から概算条件を求められた場合は、人間レビュー後に仮定値であることを明記する。

## 5. 問い合わせ時に伝えてはならない情報

- 利用者の実データ
- 個人を識別できる位置情報・走行履歴
- APIキー、秘密鍵、認証情報
- 未公開の契約書・他社見積
- セキュリティ上公開できない構成情報
- 人間レビュー前の法務判断

## 6. 回答の取り扱い

提供元から得た回答は、次を記録する。

- 回答日
- 回答者・部署
- 回答経路
- 適用される規約・契約・資料の名称と版
- 回答の有効期限
- 前提条件
- 書面回答の保存先
- 回答内容
- 未回答事項
- RouteGarage側の追加確認事項
- Go / No-Goへの影響

口頭回答のみ、適用条件不明、契約版不明、担当権限不明の場合はGo判定に使用しない。

## 7. 送信前ゲート

次をすべて満たすまで送信しない。

- [ ] プロジェクト責任者が内容を確認した
- [ ] 法務・契約観点のレビューを行った
- [ ] 運用責任者が質問内容を確認した
- [ ] セキュリティ・機密情報を確認した
- [ ] 未確定事項を確定済みと記載していない
- [ ] 走行安全要件を弱めていない
- [ ] オービス・警察位置のリアルタイム利用を質問に含めていない
- [ ] 送信先が公式の法人・営業・契約窓口である
- [ ] 問い合わせ文と回答証跡の保存先を決めた
