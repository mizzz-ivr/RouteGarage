## 7. 共通送信前チェック

### 文書・版

- [ ] 初回問い合わせ文のcommit SHAを記録した
- [ ] 送信前レビュー票のcommit SHAを記録した
- [ ] 共通前提のcommit SHAを記録した
- [ ] 送信本文とRepository上の対象版が一致している
- [ ] 詳細質問票を初回問い合わせへ添付していない

### 入力・事実確認

- [ ] 運営主体、担当者、連絡先が実在情報である
- [ ] 未確定値を確定事項として記載していない
- [ ] 仮定値には仮定であることを明記した
- [ ] 提供元・製品・問い合わせ窓口を取り違えていない
- [ ] URLを送信直前に人間が確認した

### 機密・プライバシー

- [ ] APIキー、秘密鍵、トークン、パスワードを含まない
- [ ] 利用者の実データを含まない
- [ ] 正確な位置情報、走行履歴、端末識別子を含まない
- [ ] 他社契約書、見積、非公開回答を含まない
- [ ] Repositoryへ掲載できない機密情報を含まない

### 安全性

- [ ] 走行中の画面注視・操作を前提にしていない
- [ ] 移動式取締り・警察位置のリアルタイム利用を含まない
- [ ] 取締り回避を目的とする表現を含まない
- [ ] 正確なオービス座標・走行中接近通知を許容していない

### 承認・証跡

- [ ] プロジェクト承認済み
- [ ] 法務・契約承認済み
- [ ] 運用承認済み
- [ ] セキュリティ・プライバシー承認済み
- [ ] 外部送信の明示承認済み
- [ ] 送信後証跡のアクセス制御された保管先を確定した

## 8. Go / No-Go判定規則

### Go候補

以下をすべて満たした場合のみ`Go候補`とする。

- 共通差し込み情報の必須項目が入力済み
- 仮定値の区分・根拠・承認が記録済み
- 提供元別レビュー票の必須項目が完了
- 全承認区分が承認済み
- 対象文書・commit SHAが固定済み
- 送信先を送信直前に人間が確認済み
- 証跡保管先とアクセス権限が確定済み
- 外部送信の明示承認が記録済み

### No-Go

次のいずれかに該当する場合は`No-Go`とする。

- 要入力・未確定・未承認が1件でも残る
- 送信本文と承認対象版が一致しない
- 個人情報・機密情報・認証情報の混入可能性がある
- 問い合わせ先が公式窓口か確認できない
- 走行安全・取締り回避防止要件に抵触する
- 証跡保管方法・回答管理責任者が未確定
- AIのみで承認されている

## 10. 回答証跡ルール

- 提供元回答本文、添付資料、契約文書、見積は公開Repositoryへ保存しない。
- アクセス制御された保管先に原本を保存する。
- Repositoryには次のみを記録する。
  - 問い合わせ管理番号
  - 回答日
  - 回答者・部署（公開可能な範囲）
  - 適用文書名・版
  - 公開可能な要約
  - 非公開証跡の参照ID
  - Go / No-Goへの影響
- 保管先のURL、パス、権限情報に機密性がある場合はRepositoryへ直接記載しない。
