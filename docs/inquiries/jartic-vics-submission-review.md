## 1. 送信目的

JARTIC JシステムおよびVICS符号型道路交通情報について、RouteGarageの想定利用形態に適用される契約区分、利用者表示、加工、キャッシュ、地図重畳、VICS技術開示契約、SLA等の正式な確認窓口・適用文書を特定する。

## 5. 本文レビュー

### 事実・前提

- [ ] RouteGarageを要件定義中のサービスとして説明している
- [ ] 利用者数、地図基盤、データ型式等を未確定としている
- [ ] 契約申込み・採用決定ではないことを明記している
- [ ] JARTICとVICSセンターの責務分界を断定していない
- [ ] VICS技術開示契約の正式窓口・手順を質問している
- [ ] 公開資料だけで利用許諾済みと扱っていない

### 質問範囲

- [ ] 契約区分と契約主体を確認している
- [ ] Web / モバイル利用者表示を確認している
- [ ] バックエンドからクライアントへの配信を確認している
- [ ] 加工、統合、競合判定を確認している
- [ ] 他社地図への重畳を確認している
- [ ] キャッシュ、履歴、削除義務を確認している
- [ ] 帰属、免責、表示条件を確認している
- [ ] 更新時刻、訂正、撤回、障害を確認している
- [ ] SLA・緊急連絡・停止手順を確認している
- [ ] セキュリティ・位置情報送信要否を確認している
- [ ] 費用算定に必要な前提項目のみを確認している
- [ ] 詳細質問票を初回送信へ添付していない

### 安全性・プライバシー

- [ ] 走行前または安全な場所へ停車中の確認用途としている
- [ ] 走行中の画面注視・操作を促していない
- [ ] 移動式取締り・警察位置のリアルタイム利用を含まない
- [ ] 取締り回避を目的とする表現を含まない
- [ ] 正確なオービス座標・接近通知を許容していない
- [ ] 利用者の実位置・走行履歴・識別子を含まない

### 機密・セキュリティ

- [ ] APIキー・秘密鍵・トークンを含まない
- [ ] 他社の契約書・見積・非公開回答を含まない
- [ ] 内部構成・脆弱性・認証情報を含まない
- [ ] 個人情報を必要最小限にしている
