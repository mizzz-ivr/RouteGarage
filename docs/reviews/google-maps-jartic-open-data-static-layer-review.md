# Google Maps + JARTICオープンデータ 静的レイヤー利用境界レビュー（Issue #109）

- ドキュメント種別: 要件定義〜基本設計前フェーズの利用条件・データ境界レビュー
- 対象Issue: https://github.com/mizzz-ivr/RouteGarage/issues/109
- 関連Issue: Issue #103、Issue #107
- 関連PR: PR #106、PR #108
- 確認日: 2026-07-27
- AI利用: ChatGPT支援、人間レビュー必須
- 位置付け: 採用決定、契約判断、法的助言、実装設計ではない

## 1. 目的

Google Maps Platform上でJARTICオープンデータを表示する場合の、用途、鮮度、出典、加工、第三者権利、履歴保存、Google Maps帰属、提供停止の境界を定義する。

本レビューでは、公開されている公式資料から確認できた事項と、採用前に人間・法務・運用で確認すべき事項を分離する。

## 2. 結論

C-02「Google Maps Platform + JARTICオープンデータ」は、次の評価を維持する。

`用途限定候補 / 公開MVPレイヤーとしては保留`

利用候補は、基準年月を明示した静的・定期更新レイヤー、履歴参照、交通量分析に限定する。

以下の用途には使用しない。

- 現在の渋滞、事故、工事、通行止め、所要時間の表示
- 一時的・緊急の交通規制判断
- 走行中のリアルタイム案内
- 安全判断の唯一の根拠
- 取締り回避を目的とする表示・通知

## 3. 公式資料

### 3.1 JARTIC

- 各種情報の提供（オープンデータ）
  - https://www.jartic.or.jp/service/opendata/
- オープンデータ利用規約
  - https://www.jartic.or.jp/d/opendata/riyou_kiyaku.pdf

公式ページでは次の4分類が提供されている。

1. 交通規制情報
2. 断面交通量情報
3. 交通量データ（国土交通省）
4. 交差点制御情報

各情報は原則として毎月月初に更新され、更新前の情報は提供元ページから取得できなくなる。作業状況により更新が遅れる場合がある。

### 3.2 Google Maps Platform

- Maps JavaScript API Data Layer / GeoJSON example
  - https://developers.google.com/maps/documentation/javascript/examples/layer-data-dragndrop
- Ground Overlays
  - https://developers.google.com/maps/documentation/javascript/groundoverlays
- Google Maps Platform Datasets
  - https://developers.google.com/maps/documentation/javascript/dds-datasets/create-dataset
- Google Maps Platform Service Specific Terms
  - https://cloud.google.com/maps-platform/terms/maps-service-terms

Google Maps JavaScript APIには、GeoJSON、ポイント、線、ポリゴン、画像等の利用者側データをGoogle Map上へ表示する技術機能がある。

この技術機能は、JARTICデータの権利処理、第三者権利、公開範囲、履歴保存を自動的に許可するものではない。

## 4. JARTIC利用規約から確認できた事項

### 4.1 許可される利用

JARTICオープンデータは、利用規約に従うことで次の利用が可能とされている。

- 商用利用
- 複製
- 公衆送信
- 翻訳・変形等の翻案
- 編集・加工

利用規約はCC BY 4.0と互換性がある。

### 4.2 必須表示

データを利用する際は、次を記載する。

- データ名
- 公益財団法人日本道路交通情報センター
- 対象ページURL
- 利用日

データを編集・加工した場合は、出典とは別に、RouteGarageが編集・加工したことを記載する。

加工後データをJARTIC、国、府省等が作成したかのように表示してはならない。

### 4.3 第三者権利

データ中に第三者が著作権その他の権利を持つ場合がある。

権利処理済みであることが明示されていない第三者権利については、利用者の責任で確認・許諾取得を行う必要がある。

第三者権利部分が明確に特定されていない場合もあるため、データセット全体を自動的に権利処理済みとして扱わない。

### 4.4 免責・変更

- JARTICはデータを用いた行為について責任を負わない。
- データは予告なく変更、移転、削除される場合がある。
- 利用規約は変更される場合がある。

したがって、RouteGarageは提供元の正確性・継続性を保証する表示を行わない。

## 5. データ種別ごとの用途分類

| データ種別 | 公開レイヤー候補 | 主な用途 | 禁止・注意事項 |
| --- | --- | --- | --- |
| 交通規制情報 | 条件付き候補 | 基準年月時点の規制参照 | 現在有効な一時規制・緊急規制として表示しない。第三者権利・作成基準日を確認する |
| 断面交通量情報 | 条件付き候補 | 月次交通量の分析・参考表示 | 現在の渋滞、交通流、所要時間として表示しない |
| 交通量データ（国土交通省） | 条件付き候補 | 道路利用傾向・統計参照 | JARTIC以外の上流由来、出典、第三者権利を確認する |
| 交差点制御情報 | 内部調査候補 | 信号制御・交差点構造の調査 | 利用者向け解釈、安全性、第三者権利を確認するまで公開MVPでは使用しない |

## 6. 鮮度・状態管理

### 6.1 必須メタデータ

表示単位またはレイヤー単位で、最低限次を保持する。

- データセット名
- 対象都道府県・対象地域
- 対象年月または作成基準日
- JARTIC公開更新日
- RouteGarage取得日時
- 原本ファイル名
- 原本ハッシュ
- フォーマット・説明書のバージョン
- 利用規約確認日・規約参照URL
- 加工処理のバージョン
- 第三者権利確認状態
- 表示状態

### 6.2 状態

| 状態 | 意味 | 表示方針 |
| --- | --- | --- |
| 最新公開版 | JARTICが公開している最新月次版を取得・検証済み | 基準年月を明示して静的参照表示できる |
| 更新遅延 | 想定時期を過ぎても新しい版を確認できない | 旧版を現在情報として扱わず「更新確認中」と表示する |
| 旧版・履歴 | 過去のスナップショット | 履歴・分析画面のみ。現在情報と同じ表示にしない |
| 権利確認中 | 第三者権利や上流由来が未確認 | 公開しない |
| 提供停止 | 規約変更、権利問題、誤情報、重大な不整合等 | 対象レイヤーを非表示にする |

### 6.3 表示禁止表現

月次データに対して、次の表現を使用しない。

- リアルタイム
- 現在の交通状況
- 最新の渋滞
- 現在通行止め
- 今すぐ有効な規制

## 7. 利用者向け表示要件

静的レイヤーには、次を常時または容易に確認できる位置へ表示する。

- レイヤー名
- 「静的・月次更新情報」等の情報種別
- 対象年月または作成基準日
- JARTIC公開更新日
- RouteGarage取得日
- 出典
- 加工した場合は加工表示
- 「現在の交通状況を示すものではありません」等の注意
- 情報の欠落、遅延、誤差の可能性

### 7.1 出典表示例

> 出典：「交通規制情報」（公益財団法人日本道路交通情報センター）
> https://www.jartic.or.jp/service/opendata/
> 2026年7月27日利用

### 7.2 加工表示例

> 上記データをRouteGarageが地図表示用に変換・加工して作成

実際の表示文言は、対象データ名、利用日、加工内容に合わせて生成する。

## 8. Google Maps上の表示境界

### 8.1 必須境界

- Google Maps標準帰属を削除、隠蔽、改変しない。
- JARTIC出典・加工表示をGoogle Maps標準帰属とは別に表示する。
- Google由来の地図情報とJARTIC由来レイヤーの出所を識別できるようにする。
- JARTICレイヤーの表示切替、対象年月、状態を専用UIで示す。
- GoogleがJARTICデータを作成・保証しているように表示しない。
- JARTICがGoogle地図やRouteGarageの加工結果を保証しているように表示しない。

### 8.2 Google Maps Datasetsへのアップロード

Google Maps Platform Datasets等へJARTICデータをアップロードする方式は、本Issueでは採用しない。

採用候補とする場合は、別Issueで次を確認する。

- Google側での保存場所・保存期間
- データの公開範囲
- Google・委託先による処理範囲
- 削除手順・削除完了確認
- 第三者権利データのアップロード可否
- 規約変更・契約終了時のデータ回収
- JARTIC出典・加工表示の実装方法

確認完了までは、GoogleへJARTICデータをアップロードしない。

## 9. 加工・変換境界

JARTIC原本を地図表示へ変換する場合、次を記録する。

- 入力原本ハッシュ
- 入力データセット名・対象年月
- 変換プログラム・設定のバージョン
- 座標系・位置参照変換方法
- 除外・補正・集約ルール
- 変換日時
- 変換担当・実行主体
- 変換後ハッシュ
- 品質検証結果

加工後データには、JARTIC原本そのものと誤認しない識別子を付ける。

原本の意味を変える推定、欠損補完、現在状態への推定は行わない。

## 10. 保存・履歴境界

### 10.1 保存分類

| 保存対象 | 初期方針 | 条件 |
| --- | --- | --- |
| 取得原本 | 条件付き保存候補 | アクセス制御、ハッシュ、取得証跡、第三者権利確認 |
| 正規化データ | 条件付き保存候補 | 原本との対応、変換版、加工表示を追跡できること |
| 表示用GeoJSON等 | 条件付き保存候補 | 公開範囲、第三者権利、対象年月を追跡できること |
| 過去スナップショット | 条件付き保存候補 | 現在情報と分離し、規約・権利変更時に停止・削除できること |
| 監査メタデータ | 保存候補 | データ本体を含めず、取得・変換・公開判断を追跡すること |
| 公開Repositoryへのデータ本体 | No-Go | 第三者権利、容量、更新、削除統制を確保できないため |
| Google Maps Datasetsへのアップロード | No-Go | 別途権利・保存・削除レビュー未実施のため |

### 10.2 履歴保存の考え方

JARTIC利用規約では複製・公衆送信・加工が許容されており、公開規約上の明示的な保存期間上限は確認できない。

ただし、次を理由に過去スナップショットの保存・公開を自動的にGoとしない。

- 第三者権利が含まれる可能性
- データ固有の説明書・上流条件
- 提供元による変更・移転・削除
- 規約変更
- 誤情報・訂正・権利侵害対応

履歴保存を採用する場合は、データセット・都道府県・ファイル単位で権利状態と削除可否を記録する。

## 11. 第三者権利台帳

公開候補ごとに次を記録する。

- データセット名
- 対象ファイル・項目
- 上流提供者
- 権利者表示の有無
- 第三者権利の可能性
- 権利処理済みの明示有無
- 確認した説明書・規約・資料
- 確認者・確認日
- 許可範囲
- 表示義務
- 保存・加工・公衆送信可否
- 判定: `確認済み / 条件付き / 未確認 / 非許可`
- 証跡参照ID

`未確認`または`非許可`は公開No-Goとする。

## 12. 提供停止・訂正

次のいずれかに該当する場合、対象レイヤーまたは対象データセットを提供停止する。

- 利用規約が変更され、利用可否を判断できない
- 第三者権利の問題が判明した
- 出典・加工表示に不備がある
- 対象年月・更新状態を表示できない
- 誤情報・重大な位置ずれ・不整合が報告された
- 原本と加工後データの対応を追跡できない
- データの真正性・ハッシュを確認できない
- Google Maps帰属またはJARTIC出典を正しく表示できない
- 削除・非公開要求へ対応できない

安全影響または権利侵害の可能性が高い通報を受けた場合、調査完了まで対象を一時停止する。

## 13. Go / No-Goゲート

C-02を基本設計候補へ進めるには、次をすべて満たす。

1. 利用するデータセットと用途を特定した
2. 月次・静的情報でありライブ交通として扱わない
3. 対象年月、公開更新日、取得日を表示できる
4. JARTIC出典と加工表示を実装できる
5. Google Maps標準帰属を維持できる
6. Google由来情報とJARTIC由来情報を視覚的に分離できる
7. 第三者権利をファイル・項目単位で確認した
8. 原本、変換後、表示用、履歴、監査データを分離できる
9. 規約・データ版・変換版・ハッシュを追跡できる
10. 旧版を現在情報として表示しない
11. 更新遅延、欠落、規約変更、権利問題でレイヤーを停止できる
12. Google Maps Datasets等へ無確認でアップロードしない
13. 誤情報・権利侵害通報に対応できる
14. 法務、運用、安全、プロジェクト責任者が承認した

1項目でも未確認の場合は保留またはNo-Goとする。

## 14. 初期MVP方針

公開MVPでの優先順位は次のとおりとする。

1. データ取り込み・公開より先に、第三者権利台帳と表示文言を確定する
2. 内部検証用に対象データセットを1種類へ限定する
3. 履歴・分析用途と現在参照用途を分離する
4. Googleへデータをアップロードしない構成を優先して検討する
5. 利用者向け公開は人間・法務レビュー後に判断する

本Issueでは対象データセットを採用決定しない。

## 15. リスク

- 月次情報を現在の交通状況として誤認させる
- 出典・加工表示が画面変更で欠落する
- 第三者権利をデータセット全体で確認済みと誤認する
- 提供元から消えた旧版を無期限に現在情報として使う
- 原本と加工後データの対応を失う
- Google Maps標準帰属とJARTIC出典が混在する
- Google Maps Datasetsへ無確認でアップロードする
- 規約変更・権利問題時に過去スナップショットを削除できない
- 位置ずれ・フォーマット変更を検出できない

## 16. テスト観点

### 正常系

- 最新公開版を対象年月・出典・加工表示付きで表示できる
- Google Maps帰属とJARTIC出典を同時に表示できる
- 原本から表示用データまでの変換経路を追跡できる

### 異常系

- 新しい月次版が未公開の場合に旧版を現在情報として表示しない
- 出典・対象年月・第三者権利状態が欠落した場合に公開を停止する
- フォーマット変更・変換失敗時に前月版へ自動的に現在表示を戻さない

### 境界値

- 月替わり直後で更新が遅延している状態
- 同一対象年月でファイルが差し替えられた状態
- 一部都道府県・一部ファイルだけ権利確認が未完了の状態

### 既存影響

- Google Maps標準帰属を隠さない
- C-01 Google Routesの保存禁止項目と混同しない
- JARTIC Jシステム / VICSのライブデータ契約と混同しない

## 17. ADR

追加しない。

JARTICオープンデータ、Google Maps Platform、表示方式、保存方式を採用決定していないため、ADRはprovider選定または基本設計時に作成する。
