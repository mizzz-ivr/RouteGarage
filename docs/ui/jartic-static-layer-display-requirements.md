# JARTIC静的レイヤー 出典・加工・鮮度表示要件（Issue #113）

- 対象Issue: https://github.com/mizzz-ivr/RouteGarage/issues/113
- 作成日: 2026-07-29
- フェーズ: Phase 1 / Requirements Definition（画面設計）
- 状態: 要件ドラフト / 人間・法務・運用・安全・アクセシビリティレビュー必須
- 実装状態: 未実装

## 1. 目的

JARTICオープンデータをGoogle Map上の静的・定期更新レイヤーとして将来表示する場合に、利用者が情報源、加工主体、対象時点、更新・権利状態を誤認しない画面要件を定義する。

本書は表示要件を定義するものであり、JARTICオープンデータ、Google Maps Platform、Next.js、Expo、Google Maps SDKの採用・実装を決定しない。

## 3. 公式資料

確認日: 2026-07-29

### JARTIC

- 各種情報の提供（オープンデータ）
  - https://www.jartic.or.jp/service/opendata/
- オープンデータ利用規約
  - https://www.jartic.or.jp/d/opendata/riyou_kiyaku.pdf

確認事項:

- データ利用時は出典表示が必要。
- 編集・加工時は、出典とは別に編集・加工した事実の表示が必要。
- 加工後情報をJARTIC、国、府省等が作成したものと誤認させてはならない。
- 第三者権利は利用者の責任で確認する必要がある。
- データは変更・移転・削除される場合がある。

### Google Maps Platform

- Maps JavaScript API policies and attributions
  - https://developers.google.com/maps/documentation/javascript/policies
- Add a dataset to a map
  - https://developers.google.com/maps/documentation/javascript/dds-datasets/add-dataset-to-map

確認事項:

- Google Maps Platformの帰属を削除、非表示、隠蔽、改変してはならない。
- Google Maps Platform由来の情報と他の情報を視覚的に区別する必要がある。
- 帰属はコンテンツと同じ視覚コンテナ内または近接位置に、常に判読可能な状態で配置する。
- Google Mapsロゴにはアクセシブルなコントラストとアクセシビリティラベルが必要。
- Google Mapsテキスト帰属の最小文字サイズ・コントラスト等は公式ポリシーに従う。
- アップロードしたdatasetを表示する場合も、必要なデータ帰属を地図上に表示する必要がある。

Google公式ポリシーは変更される可能性があるため、実装前およびリリース前に適用契約・最新版を再確認する。

## 4. 基本方針

1. JARTIC月次データをライブ・現在情報として表示しない。
2. `最新公開版`と`現在の交通状況`を明確に分離する。
3. Google Maps標準帰属とJARTIC出典・加工表示を別責務として扱う。
4. データセット名・対象年月・静的情報である旨は、地図レイヤー有効中に常時確認可能とする。
5. 更新・権利状態は色だけでなく、文字・アイコン・支援技術向けラベルで表現する。
6. 出典・加工表示・対象年月・公開判定を表示できない場合、そのレイヤーは表示しない。
7. 権利未確認・失効・提供停止データを「警告付きで表示継続」しない。
8. 走行中に詳細情報の閲覧、履歴比較、レイヤー切替を促さない。
9. 共有・画像・印刷・エクスポートでも出典・対象年月・加工表示を欠落させない。
10. 画面表示は将来のWeb / iOS / Androidで同じ意味になるよう、文言・状態名・優先度を共通化する。

## 5. 用語

| 用語 | 定義 |
| --- | --- |
| 対象年月 | データが対象とする年月。公開日・取得日とは別に扱う |
| 作成基準日 | データ作成の基準となる日付。対象年月がない場合に使用する |
| 公開更新日 | JARTICが公開ページ・ファイルを更新した日 |
| 取得日 | RouteGarageが原本を取得した日 |
| 検証日 | RouteGarageが原本、ハッシュ、変換結果、表示状態を確認した日 |
| 権利確認日 | 第三者権利台帳の判定を確認した日 |
| 最新公開版 | JARTICが現在公開している版。現在月・現在有効・リアルタイムを意味しない |
| 静的参照情報 | 対象年月・作成基準日時点の参考情報。現在の交通判断には使用しない |
| 加工表示 | RouteGarageが編集・加工したことを利用者へ示す表示 |
| 提供停止 | 権利、安全、規約、真正性等の理由でレイヤーを利用者へ表示しない状態 |

## 6. 情報の表示レベル

### 6.1 常時表示

JARTICレイヤーが地図上で有効な間、次を地図画面内で常時確認可能とする。

- レイヤー名またはデータセット名
- `静的・月次更新情報`ラベル
- 対象年月または作成基準日
- 現在の交通状況ではない旨
- 状態ラベル
  - 利用可能
  - 更新遅延
  - 旧版
  - 条件付き
- JARTIC出典詳細を開く導線
- RouteGarageが加工している場合は`RouteGarage加工`ラベル

常時表示情報は、出典詳細を開かなくても「誰の・いつの・どの性質の情報か」を判断できる粒度とする。

### 6.2 1操作以内で表示

停車中・走行前の状態では、次を1操作以内で確認できるようにする。

- 正式なデータセット名
- JARTICの正式名称
- JARTIC公開ページURL
- 利用日または参照日
- 公開更新日
- RouteGarage取得日
- RouteGarage検証日
- 権利確認状態・確認日
- 上流提供者・追加帰属
- RouteGarageの加工内容要約
- 欠落・遅延・誤差・位置ずれの可能性
- 利用目的と禁止用途
- 過去版である場合の履歴状態

### 6.3 内部運用だけで表示

次は利用者向け画面へ表示せず、運用台帳・監査画面で管理する。

- 原本ファイル名
- 原本ハッシュ
- 利用規約文書ハッシュ
- 証跡参照ID
- 非公開契約・許諾情報
- 承認者の個人情報
- 停止・調査の内部メモ

## 7. 対象画面別要件

## 7.1 地図画面

### 必須要件

- JARTICレイヤーの有効・無効を利用者が判別できる。
- レイヤー有効時は、対象年月と`静的情報`を同一視認領域に表示する。
- Google Maps標準帰属を覆わない、移動しない、改変しない。
- JARTIC出典表示はGoogle Maps帰属と混在させず、別の表示領域または明確に区切られた領域に置く。
- Google由来、JARTIC由来、RouteGarage独自情報を凡例・ラベル・線種・アイコンで区別する。
- 色だけで区別しない。
- JARTICレイヤーの状態が`権利確認中`、`非許可`、`失効・再確認必要`、`提供停止`の場合、地物を地図上に描画しない。
- 更新遅延・旧版の場合、情報を表示するか否かは権利台帳・運用判定に従う。表示する場合は地物と同じ視認領域に状態を表示する。

### 推奨レイアウト

Web:

- デスクトップ: 地図上部またはサイドパネル上部にレイヤー状態カードを配置する。
- 狭幅: 地図下部に固定しないコンパクトな状態バーを配置し、Google Maps帰属を覆わない。

将来モバイル:

- 地図下部のシート最上部または上部セーフエリア内に状態を表示する。
- Google Maps帰属、OSジェスチャー領域、ホームインジケータを覆わない。
- 走行中状態では詳細シートを展開しない。

### 常時表示文言例

通常:

> JARTIC静的情報｜対象: 2026年6月｜現在の交通状況ではありません

更新遅延:

> JARTIC静的情報｜対象: 2026年5月｜公開更新を確認中

旧版・履歴:

> 過去版｜対象: 2025年12月｜履歴参照用

加工あり:

> JARTIC公開データをRouteGarageが表示用に加工

文言は例であり、法務・運用レビュー後に確定する。

## 7.2 レイヤー選択・凡例

- レイヤー名の直下に`静的・月次更新`を表示する。
- 対象年月をレイヤー名の補助情報として表示する。
- ライブ交通レイヤーと同じカテゴリ・トグル群へ混在させない。
- `最新`だけの表記を禁止する。
- 利用不可状態ではトグルを無効にし、理由と再確認導線を表示する。
- 無効理由は色や鍵アイコンだけでなく文字で表示する。
- 停止中のレイヤーを初期ONにしない。
- 凡例には、JARTIC由来・RouteGarage加工・過去版を識別する記号を含める。

## 7.3 地物詳細パネル

地物を選択した場合、次を表示する。

- 地物の表示名
- データセット名
- 対象年月・作成基準日
- 静的参照情報である旨
- JARTIC出典
- 上流提供者・追加帰属
- RouteGarage加工表示
- 状態
- 注意事項
- データセット詳細への導線

禁止:

- `現在通行止め`
- `今の規制`
- `リアルタイム`
- `この道路は安全`
- 現在時刻との差だけで鮮度を安全側に推測する表示

## 7.4 データセット詳細・出典画面

次を一覧表示する。

| 項目 | 必須 |
| --- | --- |
| データセット名 | 必須 |
| 提供元 | 必須 |
| 公開ページURL | 必須 |
| 対象年月・作成基準日 | 必須 |
| JARTIC公開更新日 | 必須 |
| RouteGarage取得日 | 必須 |
| RouteGarage検証日 | 必須 |
| 権利確認状態・確認日 | 必須 |
| 上流提供者・追加帰属 | 条件付き必須 |
| 加工内容 | 加工時必須 |
| 静的情報の注意文 | 必須 |
| 欠落・遅延・誤差・位置ずれ | 必須 |
| 履歴・過去版の有無 | 必須 |
| 通報・問い合わせ導線 | 必須 |

日付項目は、単に`更新日`へ統合しない。

## 7.5 履歴・過去版画面

- 画面タイトルに`履歴`または`過去版`を含める。
- 現在表示中の対象年月を明示する。
- 最新公開版との違いを表示する。
- 最新公開版へ切り替える導線は提供できるが、現在情報へ切り替えるとは表現しない。
- 過去版を地図へ表示する場合、画面全体に履歴モードであることを表示する。
- 履歴版と最新公開版を同じ線種・同じラベルで重ねない。
- 走行中に履歴比較機能を提供しない。

## 7.6 更新遅延・権利確認中・提供停止

### 更新遅延

- 取得済み旧版を表示する場合は、対象年月と更新確認中を常時表示する。
- 旧版を現在情報として自動昇格しない。
- 更新遅延の原因を推測表示しない。

### 権利確認中

- 対象地物を利用者向け地図へ表示しない。
- `確認中のため非表示`と表示できる。
- 権利確認完了予定日を推測表示しない。

### 提供停止

- 停止対象地物を地図上から除去する。
- 直前に表示していた内容をキャッシュで残さない。
- 停止理由は公開可能な範囲に限定する。
- `データがありません`と`提供停止`を区別する。

## 7.7 データなし・取得失敗・検証失敗

| 状態 | 利用者向け表示 | 地図描画 |
| --- | --- | --- |
| 対象データなし | 対象年月にデータがない旨 | しない |
| 取得失敗 | データを取得できない旨 | しない、または承認済み旧版のみ明示表示 |
| 検証失敗 | 検証できないため停止した旨 | しない |
| ハッシュ不一致 | 提供停止 | しない |
| 権利状態失効 | 権利確認が必要なため停止 | しない |

失敗を通常の空データと同じ表示にしない。

## 7.8 共有・スクリーンショット・印刷・エクスポート

公開候補とする場合、出力物に次を含める。

- データセット名
- 対象年月・作成基準日
- JARTIC出典
- RouteGarage加工表示
- 静的情報である旨
- 出力日
- Google Maps由来コンテンツを含む場合は適用されるGoogle Maps帰属

次の場合はNo-Goとする。

- 帰属・対象年月が出力範囲外になる
- Google Maps標準帰属を画像加工で除去する
- 第三者権利台帳でエクスポートが未確認・非許可
- 非公開証跡・内部ID・利用者の正確な位置を意図せず含む
- 停止・失効中の地物を出力する

実装可否はprovider・利用方法ごとに別途確認する。

## 8. 表示状態モデル

| 状態コード候補 | 利用者向け名称 | 地図表示 | 操作 | 主な条件 |
| --- | --- | --- | --- | --- |
| AVAILABLE_STATIC | 静的参照 | 条件付き表示 | 詳細確認可能 | 権利・表示・鮮度ゲート充足 |
| UPDATE_DELAYED | 更新確認中 | 承認済み旧版のみ条件付き | 詳細確認可能 | 公開更新遅延、旧版利用許可あり |
| HISTORICAL | 過去版 | 履歴モードのみ | 走行前・停車中のみ | 履歴公開許可あり |
| CONDITIONAL | 条件付き公開 | 条件強制時のみ | 制限付き | 期限・範囲・表示義務あり |
| RIGHTS_REVIEW | 権利確認中 | 非表示 | なし | 調査中・再確認中 |
| SUSPENDED | 提供停止 | 非表示 | なし | 権利・安全・規約・真正性問題 |
| NO_DATA | データなし | 非表示 | なし | 対象データなし |
| FETCH_FAILED | 取得失敗 | 原則非表示 | 再試行導線候補 | 取得失敗 |
| VERIFICATION_FAILED | 検証失敗 | 非表示 | なし | ハッシュ・変換・検証失敗 |

状態コードは実装確定ではなく、画面・API・運用間で意味を揃えるための候補である。

## 9. 禁止表現

以下は月次・静的レイヤーに使用しない。

- リアルタイム
- 現在の交通情報
- 最新交通情報
- 現在の渋滞
- 現在通行止め
- 今の規制
- 最新の規制
- 通行可能です
- 安全です
- この情報に従えば問題ありません
- 常に正確です
- 公式が保証しています

`最新公開版`を表示する必要がある場合は、対象年月と「現在情報ではない」旨を同時表示する。

## 10. 出典・加工表示の文言要件

### 出典候補

> 出典: 「{データセット名}」（公益財団法人日本道路交通情報センター）（{公開ページURL}、{利用日}利用）

### 加工表示候補

> JARTIC公開データをRouteGarageが表示用に編集・加工しています。

### 注意文候補

> 対象年月時点の静的情報です。現在の渋滞、事故、通行止め、緊急規制を示すものではありません。

### 追加帰属

第三者権利台帳で上流提供者・権利者の追加表示が必要な場合、JARTIC出典とは別行または明確に区切った領域へ表示する。

最終文言は法務・運用レビュー後に確定する。

## 11. Google Maps帰属との責務分離

### Google Maps帰属

- Google Maps Platform由来コンテンツの帰属として扱う。
- Googleが提供する帰属を削除、非表示、隠蔽、改変しない。
- 公式のサイズ、コントラスト、アクセシビリティ要件へ従う。
- Google Maps由来コンテンツとJARTIC・RouteGarage情報を視覚的に区別する。

### JARTIC出典・加工表示

- RouteGarageが追加する第三者データの出典・加工表示として扱う。
- Google MapsロゴだけでJARTIC出典を代替しない。
- JARTIC出典をGoogle MapsがJARTICデータを提供・保証しているように配置しない。
- JARTIC出典とGoogle Maps帰属を一つの曖昧な`提供元`表示へ統合しない。

### 配置

- Google Maps標準帰属を覆わない。
- JARTIC出典は地図のカスタムコントロール、状態カード、詳細パネル等で常時確認可能とする。
- 小画面でも両方の帰属を判読できない場合、当該レイアウトでのレイヤー表示はNo-Goとする。

## 12. アクセシビリティ要件

- 状態を色だけで表現しない。
- 状態ラベルへ文字と意味のあるアイコンを併用する。
- スクリーンリーダー向けに、レイヤー名・対象年月・状態・静的情報の注意を読み上げる。
- アイコンだけの操作にはアクセシブルネームを付与する。
- Google Mapsロゴ・テキスト帰属は公式アクセシビリティ要件に従う。
- 文字と背景のコントラストは少なくともWCAG 2.2 AA相当を目標とする。
- 通常テキストは4.5:1以上、大きなテキスト・UI境界は適用基準を満たす。
- キーボードだけでレイヤー状態、凡例、詳細、閉じる操作へアクセスできる。
- フォーカス順序は地図操作、状態表示、詳細の論理順とする。
- 詳細パネル表示時にフォーカスを適切に移し、閉じた後は起点へ戻す。
- 点滅・自動スクロール・強制アニメーションで状態を伝えない。
- 更新状態の変化は必要に応じて控えめなライブリージョンで通知し、連続読み上げを避ける。

## 13. レスポンシブ要件

### デスクトップ

- 地図を隠しすぎないサイドパネルまたは状態カードを使用する。
- 出典詳細と地物詳細を同時表示する場合もGoogle Maps帰属を覆わない。
- キーボード操作とズーム時のレイアウト崩れを確認する。

### タブレット

- 横向き・縦向きで状態ラベルと対象年月が常時見える。
- サイドパネルとボトムシートを画面幅に応じて切り替える候補とする。

### モバイル

- 重要情報は省略せず、`静的情報`・対象年月・状態を優先表示する。
- 出典詳細を折りたたむ場合でも、提供元・対象年月・加工有無・注意文への導線を残す。
- セーフエリアとOSジェスチャー領域を避ける。
- 画面高さが小さい場合、地図レイヤー表示より帰属・状態表示を優先する。
- 両方の帰属を表示できない極端なサイズではレイヤーを表示しない。

## 14. 走行状態別要件

| 状態 | 許可する表示・操作 |
| --- | --- |
| 走行前 | レイヤー選択、詳細、出典、履歴確認が可能 |
| 停車中 | 走行前と同等。ただし停車判定の実装は別Issue |
| 走行中 | 状態・対象年月・静的情報の最小表示のみ。詳細展開、履歴比較、レイヤー切替を促さない |
| 状態不明 | 走行中と同等の安全側表示候補 |

- 走行中に画面操作を要求するエラー回復を設けない。
- 出典詳細を読むことを走行中に要求しない。
- 静的レイヤーを音声で現在規制として案内しない。
- 走行中に更新遅延・提供停止を強い警告音や点滅で通知しない。

## 15. 受け入れ条件

### 正常系

- レイヤー有効時に、レイヤー名・対象年月・静的情報・状態が常時確認できる。
- 出典詳細を1操作以内で開ける。
- JARTIC出典と加工表示が正しく表示される。
- Google Maps帰属が常に表示される。
- Google、JARTIC、RouteGarage由来情報を区別できる。

### 状態別

- 更新遅延を最新・現在情報として表示しない。
- 過去版が履歴モードとして明示される。
- 権利確認中・失効・停止の地物が描画されない。
- データなし、取得失敗、検証失敗、停止を区別する。

### 境界値

- 長いデータセット名・上流提供者名でも帰属が欠落しない。
- 対象年月・公開更新日・取得日が異なる場合も混同しない。
- 小画面・200%ズーム・文字サイズ拡大時も重要情報が表示される。
- ダークモード・ライトモードで帰属と状態のコントラストを維持する。

### 異常系

- 出典情報が欠落している場合、レイヤーを表示しない。
- 権利状態が不明の場合、レイヤーを表示しない。
- ハッシュ・版・変換対応が不明の場合、提供停止する。
- Google Maps帰属を表示できない場合、Google Mapを表示しない。
- JARTIC出典を表示できない場合、JARTICレイヤーを表示しない。

### 共有・印刷

- 出典・対象年月・加工表示が出力に含まれる。
- 停止・非許可・未確認データを出力できない。
- 正確な利用者位置・内部証跡を意図せず含まない。

### アクセシビリティ

- キーボードだけで操作可能。
- スクリーンリーダーでレイヤー名・対象年月・状態・注意文を理解できる。
- 色覚に依存せず状態を識別できる。
- フォーカスが見える。
- 帰属・注意文のコントラストが基準を満たす。

## 16. レビュー観点

- 月次データを現在の交通情報として誤認させないか。
- 対象年月、公開更新日、取得日、検証日、権利確認日が分離されているか。
- 出典を詳細画面だけに隠していないか。
- Google Maps帰属とJARTIC出典を混同していないか。
- 加工情報をJARTIC作成物と誤認させないか。
- 色だけで状態を表現していないか。
- 小画面で帰属が欠落・重複・重なりを起こさないか。
- 走行中に詳細確認・レイヤー切替を促していないか。
- 停止・失効中の地物がキャッシュ表示されないか。
- 共有・画像・印刷で帰属が失われないか。

## 17. Go / No-Goゲート

次をすべて満たす場合のみ、画面基本設計の候補へ進める。

1. 表示対象データの権利台帳がGo候補または強制可能な条件付きGoである。
2. 対象年月・作成基準日を表示できる。
3. JARTIC公開更新日・RouteGarage取得日・検証日を追跡できる。
4. JARTIC出典を表示できる。
5. 加工時に加工表示を表示できる。
6. 上流提供者・第三者帰属を必要に応じて表示できる。
7. Google Maps標準帰属を維持できる。
8. Google・JARTIC・RouteGarage由来情報を区別できる。
9. 更新遅延、過去版、権利確認中、停止等を区別できる。
10. 色だけに依存しない。
11. Web・将来モバイル・拡大表示で重要情報を維持できる。
12. 走行中に詳細操作を促さない。
13. 共有・印刷時に出典・対象年月を維持できる。
14. 出典・状態欠落時にレイヤーを停止できる。
15. 人間・法務・運用・安全・アクセシビリティレビューが完了している。

1項目でも未確認または実現不能の場合は保留またはNo-Goとする。
