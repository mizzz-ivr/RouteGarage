## 1. 目的

JARTICオープンデータをGoogle Map上の静的・定期更新レイヤーとして将来表示する場合に、利用者が情報源、加工主体、対象時点、表示可否、鮮度、検証、権利、安全上の限界を誤認しない画面要件を定義する。

本書は表示要件を定義するものであり、JARTICオープンデータ、Google Maps Platform、Next.js、Expo、Google Maps SDKの採用・実装を決定しない。

## 4. 基本方針

1. JARTIC月次データをライブ・現在情報として表示しない。
2. 情報本体の表示中は`参考情報`であることを固定表示する。
3. `最新公開版`と`現在の交通状況`を明確に分離する。
4. 表示可否、鮮度、検証、権利状態を独立して保持する。
5. 利用者向け状態は独立軸から導出し、`STOPPED`を最優先にする。
6. Google Maps帰属とJARTIC出典・RouteGarage加工表示を別責務として扱う。
7. 情報本体の表示中は、情報源・提供元更新時点・状態・安全上の限界を固定表示する。
8. 状態は色だけでなく文字・アイコン・支援技術向けラベルで表現する。
9. 権利不明、期限切れ、競合、検証失敗、提供停止のデータを表示継続しない。
10. 走行状態を判定できない場合は、安全のため操作を制限中であることを固定表示する。
11. 走行中・状態不明時に固定必須表示を維持できない場合は情報本体を非表示にする。
12. 共有・画像・印刷・エクスポートでは、帰属だけでなく生活拠点推定リスクを確認する。
13. Web / 将来のiOS / Androidで状態名・意味・優先度を共通化する。

## 5. 用語

| 用語 | 定義 |
| --- | --- |
| 対象年月 | データが対象とする年月。公開日・取得日とは別に扱う |
| 作成基準日 | データ作成の基準日。対象年月がない場合に使用する |
| 提供元更新時点 | JARTICが示す公開更新日・基準時点。RouteGarage取得時刻で代替しない |
| 取得日 | RouteGarageが原本を取得した日 |
| 検証日 | RouteGarageが原本、ハッシュ、変換結果、競合を確認した日 |
| 権利確認日 | 第三者権利台帳の判定を確認した日 |
| 最新公開版 | JARTICが現在公開している版。現在月・現在有効・リアルタイムを意味しない |
| 静的参照情報 | 対象年月・作成基準日時点の参考情報。現在の交通判断には使用しない |
| 加工表示 | RouteGarageが編集・加工した事実を示す表示 |
| 制限表示 | 事前定義・承認された条件と固定注意の下でのみ許可される表示 |
| 提供停止 | 権利、安全、規約、真正性等の理由で情報本体を表示しない状態 |

## 6. 独立状態軸と導出ルール

単一コードで表示可否・鮮度・検証・権利を兼ねない。

### 6.1 表示可否

| 状態 | 意味 | 情報本体 |
| --- | --- | --- |
| DISPLAYABLE | 通常表示要件を満たす | 表示候補 |
| LIMITED | 定義済み制限表示ルールの全条件を満たす | 制限表示候補 |
| STOPPED | 権利・規約・期限・検証・安全判断等で表示不可 | 非表示 |

優先順位は `STOPPED` > `LIMITED` > `DISPLAYABLE` とする。

### 6.2 鮮度状態

| 状態 | 意味 |
| --- | --- |
| WITHIN_STATIC_BASELINE | 対象年月・提供元更新時点を取得し、静的レイヤー基準内 |
| DELAYED | 公開更新遅延または期待更新なし |
| UPDATE_TIME_UNKNOWN | 提供元更新時点を確認できない |
| EXPIRED | 定義済み有効期限を超過 |
| HISTORICAL | 過去版として明示管理 |

### 6.3 検証状態

| 状態 | 意味 |
| --- | --- |
| VERIFIED | 原本・ハッシュ・変換・対応関係を確認済み、既知の競合なし |
| UNVERIFIED | 検証未完了または根拠不足 |
| CONFLICTED | 複数情報・原本・変換結果に不一致あり |
| VERIFICATION_FAILED | ハッシュ、真正性、変換、対象地点対応等を検証できない |

### 6.4 権利状態

| 状態 | 意味 |
| --- | --- |
| RIGHTS_CONFIRMED | 権利台帳の必要項目と承認が揃う |
| RIGHTS_CONDITIONAL | 条件・期限・表示義務を強制できる場合だけ候補 |
| RIGHTS_REVIEW | 調査中・再確認中 |
| RIGHTS_DENIED | 非許可 |
| RIGHTS_EXPIRED | 失効・再確認期限超過 |

### 6.5 導出順序

1. 権利・契約・必須メタデータを確認する。
2. `STOPPED`条件が1つでもあれば情報本体を非表示にする。
3. 鮮度を判定し、提供元更新時点をRouteGarage取得時刻で代替しない。
4. 検証を判定し、競合・検証失敗を推測で解消しない。
5. 権利状態を判定し、未確認・失効を許可として扱わない。
6. 通常表示条件を満たさず、承認済み制限表示ルールもない場合は`STOPPED`とする。
7. 複数の不利な条件が成立した場合は、最も制限の強い状態を採用する。

例:

- `DELAYED`かつ`RIGHTS_EXPIRED`は`STOPPED`。
- `HISTORICAL`かつ`VERIFIED`でも履歴公開権限が未確認なら`STOPPED`。
- `UPDATE_TIME_UNKNOWN`は承認済み制限表示ルールがなければ`STOPPED`。

## 7. 固定必須表示・詳細表示・内部情報

### 7.1 情報本体表示中の固定必須表示

走行状態にかかわらず、次を地図画面の固定領域で常時確認可能とする。

- レイヤー名・データセット名
- 情報源・提供元
- `参考情報`
- `静的・月次更新情報`
- 対象年月・作成基準日
- 提供元更新時点
- 鮮度状態
- 検証状態
- `LIMITED`の場合は制限表示である旨
- キャッシュ表示の場合はキャッシュである旨
- 欠落・更新遅延・誤差・実際の状況との差異があり得る旨
- 本情報のみを運転判断の唯一の根拠にしない旨
- 詳細操作は安全な場所に停車してから行う旨
- JARTIC出典詳細への導線
- 加工時の`RouteGarage加工`表示

小画面・走行中・状態不明時に全項目を維持できない場合は、項目を省略せずJARTICレイヤー本体を非表示にする。

固定表示文言例:

> JARTIC参考情報｜静的・月次更新｜対象: 2026年6月｜提供元更新: 2026年7月1日｜現在情報ではありません｜欠落・遅延・誤差の可能性あり｜運転判断の唯一の根拠にしないでください｜詳細操作は安全な場所に停車してから

### 7.2 走行前・停車中に1操作以内で表示

- 正式なデータセット名
- JARTIC正式名称・公開ページURL・利用日
- RouteGarage取得日・検証日・権利確認日
- 表示可否・鮮度・検証・権利の4軸
- 上流提供者・追加帰属
- RouteGarage加工内容
- 欠落・遅延・誤差・位置ずれの詳細
- 利用目的・禁止用途
- 制限表示・キャッシュ表示の許可条件と有効期限
- 過去版である場合の履歴状態

### 7.3 内部運用だけで表示

- 原本ファイル名・ハッシュ
- 利用規約文書ハッシュ
- 証跡参照ID
- 非公開契約・許諾情報
- 承認者の個人情報
- 制限表示・キャッシュ表示の承認記録
- 停止・調査の内部メモ

## 8. 対象画面別要件

### 8.1 地図画面

- 情報本体表示中は7.1の全固定表示を維持する。
- Google Maps標準帰属を覆わない、移動しない、改変しない。
- JARTIC出典をGoogle Maps帰属と明確に分離する。
- Google由来、JARTIC由来、RouteGarage独自情報を凡例・ラベル・線種・アイコンで区別する。
- 色だけで区別しない。
- 表示可否が`STOPPED`の場合、情報本体・地物を描画しない。
- `RIGHTS_REVIEW`、`RIGHTS_DENIED`、`RIGHTS_EXPIRED`、`CONFLICTED`、`VERIFICATION_FAILED`、`EXPIRED`は原則`STOPPED`へ導出する。

### 8.2 レイヤー選択・凡例

- レイヤー名直下に`参考情報`、`静的・月次更新`、対象年月を表示する。
- ライブ交通レイヤーと同じカテゴリ・トグル群へ混在させない。
- `最新`だけの表記を禁止する。
- 利用不可時はトグルを無効にし、理由を文字で表示する。
- 停止中レイヤーを初期ONにしない。

### 8.3 地物詳細

- 地物表示名
- データセット名
- 対象年月・作成基準日
- 提供元更新時点
- 参考情報・静的参照情報である旨
- JARTIC出典・追加帰属
- RouteGarage加工表示
- 表示可否・鮮度・検証・権利状態
- 安全上の注意
- データセット詳細への導線

次の表現を禁止する。

- 現在通行止め
- 今の規制
- リアルタイム
- この道路は安全
- 現在時刻との差だけで鮮度を推測する表示

### 8.4 データセット詳細・出典

| 項目 | 必須 |
| --- | --- |
| データセット名・提供元 | 必須 |
| 公開ページURL | 必須 |
| 対象年月・作成基準日 | 必須 |
| 提供元更新時点 | 必須 |
| RouteGarage取得日・検証日 | 必須 |
| 権利確認状態・確認日 | 必須 |
| 表示可否・鮮度・検証・権利の4軸 | 必須 |
| 上流提供者・追加帰属 | 条件付き必須 |
| 加工内容 | 加工時必須 |
| 参考情報・静的情報・安全注意 | 必須 |
| 欠落・遅延・誤差・位置ずれ | 必須 |
| 履歴・過去版の有無 | 必須 |
| 通報・問い合わせ導線 | 必須 |

日付項目を単一の`更新日`へ統合しない。

### 8.5 履歴・過去版

- タイトルに`履歴`または`過去版`を含める。
- 対象年月を明示する。
- 最新公開版との差異を表示する。
- `現在情報へ切り替える`とは表現しない。
- 過去版地図では画面全体に履歴モードを表示する。
- 走行中に履歴比較を提供しない。

### 8.6 更新遅延・権利確認中・提供停止

更新遅延:

- 旧版の制限表示は、権利・契約・鮮度・検証・承認条件をすべて満たす場合だけ許可する。
- 対象年月、提供元更新時点、更新確認中、制限表示を固定表示する。
- 旧版を現在情報として自動昇格しない。

権利確認中・提供停止:

- 情報本体・地物を表示しない。
- 直前表示内容をキャッシュで残さない。
- `データなし`と`提供停止`を区別する。

### 8.7 データなし・取得失敗・検証失敗

| 状態 | 利用者向け表示 | 情報本体 |
| --- | --- | --- |
| 対象データなし | 対象年月にデータなし | 非表示 |
| 取得失敗 | 現在取得失敗中 | 原則非表示。全キャッシュ条件充足時のみ制限表示 |
| 検証失敗 | 検証できないため停止 | 非表示 |
| ハッシュ不一致 | 提供停止 | 非表示 |
| 権利状態失効 | 権利再確認のため停止 | 非表示 |

## 9. 取得失敗時のキャッシュ再表示

取得済み旧版・キャッシュを表示できるのは、次をすべて満たす場合に限る。

1. 利用規約・契約でキャッシュ保存と再表示が許可されている。
2. 提供元更新時点を取得済みである。
3. 情報種別ごとに事前承認されたキャッシュ有効期限内である。
4. 契約停止、規約変更、提供元による無効化・撤回、改ざん・完全性懸念がない。
5. 上流由来、調達経路、検証状態を追跡でき、競合がない。
6. `現在取得失敗中`、`キャッシュ情報`、`提供元更新時点`を固定表示できる。
7. 情報種別ごとの制限表示ルール、承認者、承認記録がある。

1つでも満たさない場合は`STOPPED`とする。有効期限内でも撤回、破損、完全性懸念、権利失効、安全判断不能時は停止する。

## 10. 共有・スクリーンショット・印刷・エクスポート

出力候補には次を含める。

- データセット名
- 対象年月・作成基準日
- 提供元更新時点
- JARTIC出典
- RouteGarage加工表示
- 参考情報・静的情報である旨
- 出力日
- 必要なGoogle Maps帰属

### 10.1 位置・生活拠点プライバシー

共有前に次を必須とする。

- 自宅・職場・開始地点・終了地点・反復訪問地点周辺への機械的ぼかし
- 道路形状、表示中心、履歴からの生活拠点再推定リスク確認
- 共有前プレビューで、ぼかし結果、対象範囲、帰属、対象年月を確認
- ぼかし解除を公開初期値にしない
- ぼかし後も再推定リスクが残る旨を表示
- 正確位置、非公開走行履歴、内部証跡を含む場合は出力しない

ぼかしアルゴリズム・距離閾値が未確定の間、位置・走行履歴を含む共有出力はNo-Goとする。

### 10.2 出力No-Go条件

- 帰属・対象年月・提供元更新時点が欠落する。
- Google Maps帰属を画像加工で除去する。
- 第三者権利台帳でエクスポートが未確認・非許可。
- 自宅・職場等のぼかしと共有前プレビューを実施できない。
- 正確位置、開始・終了地点、反復訪問地点、内部証跡を含む。
- 停止・失効中の地物を出力する。

## 11. 禁止表現

- リアルタイム
- 現在の交通情報
- 最新交通情報
- 現在の渋滞
- 現在通行止め
- 今の規制
- 最新の規制
- 通行可能です
- 安全です
- 常に正確です
- 公式が保証しています

`最新公開版`を表示する場合は、対象年月と現在情報ではない旨を同時表示する。

## 12. 文言候補

出典:

> 出典: 「{データセット名}」（公益財団法人日本道路交通情報センター）（{公開ページURL}、{利用日}利用）

加工表示:

> JARTIC公開データをRouteGarageが表示用に編集・加工しています。

参考情報・限界:

> 参考情報です。対象年月時点の静的情報であり、現在の渋滞、事故、通行止め、緊急規制を示すものではありません。欠落・遅延・誤差や実際の状況との差異があり得ます。

安全注意:

> 本情報のみを運転判断の唯一の根拠にしないでください。詳細操作は安全な場所に停車してから行ってください。

状態不明時:

> 走行状態を確認できないため、安全のため操作を制限中です。

位置情報共有:

> 自宅・職場・開始地点・終了地点の周辺をぼかしています。ぼかし後も生活拠点を推定される可能性があります。共有前にプレビューを確認してください。

最終文言は法務・安全・運用レビュー後に確定する。

## 13. Google Maps帰属との責務分離

- Googleが提供する帰属を削除、非表示、隠蔽、改変しない。
- Google MapsロゴだけでJARTIC出典を代替しない。
- JARTIC出典をGoogleがJARTIC情報を提供・保証したように配置しない。
- 一つの曖昧な`提供元`表示へ統合しない。
- 小画面で固定必須表示と両方の帰属を判読できない場合はJARTICレイヤーを表示しない。

## 14. アクセシビリティ要件

- 状態を色だけで表現しない。
- 状態ラベルへ文字と意味のあるアイコンを併用する。
- スクリーンリーダー向けに、参考情報、情報源、対象年月、提供元更新時点、鮮度、検証、表示可否、安全注意を読み上げる。
- 状態不明時の操作制限理由を読み上げる。
- アイコン操作にアクセシブルネームを付与する。
- コントラストはWCAG 2.2 AA相当を目標とする。
- キーボード操作、論理的フォーカス順、フォーカス復帰を定義する。
- 点滅、自動スクロール、強制アニメーションだけで状態を伝えない。

## 15. レスポンシブ要件

- デスクトップ、タブレット、モバイルで7.1の固定必須表示を維持する。
- Google Maps帰属を覆わない。
- モバイルではセーフエリアとOSジェスチャー領域を避ける。
- 200%ズーム、文字拡大、ライト・ダークモードで重要情報を維持する。
- 画面サイズ不足時は固定必須表示を省略せず、JARTICレイヤー本体を非表示にする。

## 16. 走行状態別要件

| 状態 | 許可する表示・操作 |
| --- | --- |
| 走行前 | レイヤー選択、詳細、出典、履歴確認が可能 |
| 停車中 | 走行前と同等。停車判定の実装は別Issue |
| 走行中 | 情報本体を表示する場合は7.1の固定必須表示をすべて維持する。詳細展開・履歴比較・レイヤー切替を促さない |
| 状態不明 | 走行中と同等の安全側制御に加え、`安全のため操作を制限中`を固定表示する |

走行中・状態不明時に固定必須表示を維持できない場合は、項目を省略せずJARTICレイヤー本体を非表示にする。

- 状態不明時に無効化した操作の理由を文字・支援技術で説明する。
- 走行中に操作を要求するエラー回復を設けない。
- 出典詳細の閲覧を走行中に要求しない。
- 静的情報を現在規制として音声案内しない。
- 強い警告音や点滅で更新遅延・停止を通知しない。

## 17. 受け入れ条件

### 状態・安全

- 表示可否・鮮度・検証・権利を独立保持する。
- `STOPPED`が他の状態より優先される。
- 更新遅延中の権利失効・競合・検証失敗で情報本体が残らない。
- 情報本体表示中は`参考情報`を含む7.1の固定必須表示を維持する。
- 走行中に固定必須表示を維持できない場合、レイヤー本体が非表示になる。
- 状態不明時に`安全のため操作を制限中`を固定表示する。

### 取得失敗

- 旧版再表示は7つのキャッシュ条件をすべて満たす場合だけ可能。
- 条件不足、撤回、完全性懸念、期限切れ、権利失効時は停止する。

### 帰属・レスポンシブ

- JARTIC出典・加工表示とGoogle Maps帰属を確認できる。
- Google、JARTIC、RouteGarage由来情報を区別できる。
- 小画面、200%ズーム、文字拡大、ライト・ダークモードで重要表示を維持する。

### 共有・プライバシー

- 共有前に自宅・職場・開始・終了・反復訪問地点周辺のぼかしを適用できる。
- 共有前プレビューでぼかし結果と出力内容を確認できる。
- ぼかし未実装・未確認時は位置・走行履歴を含む出力がNo-Goになる。
- 正確位置・非公開情報・内部証跡を意図せず含まない。

### アクセシビリティ

- キーボードだけで操作可能。
- スクリーンリーダーで参考情報、情報源、対象年月、4軸状態、安全注意、操作制限理由を理解できる。
- 色覚だけに依存せず状態を識別できる。

## 18. Go / No-Goゲート

1. 権利台帳がGo候補または強制可能な条件付きGoである。
2. 表示可否・鮮度・検証・権利状態を独立保持できる。
3. `STOPPED`を最優先に導出できる。
4. `参考情報`を含む固定必須表示を情報本体表示中に維持できる。
5. JARTIC出典、加工表示、追加帰属を表示できる。
6. Google Maps標準帰属を維持できる。
7. 取得失敗時の7キャッシュ条件を強制できる。
8. 色だけに依存しない。
9. Web・将来モバイル・拡大表示で重要表示を維持できる。
10. 走行中に固定必須表示を維持できない場合、情報本体を停止できる。
11. 状態不明時に操作制限理由を固定表示できる。
12. 共有前の生活拠点ぼかしとプレビューを強制できる。
13. 共有・印刷時に出典・対象年月・提供元更新時点を維持できる。
14. 欠落・失効・競合・検証失敗時に情報本体を停止できる。
15. 人間・法務・運用・安全・プライバシー・アクセシビリティレビューが完了している。

1項目でも未確認・実現不能の場合は保留またはNo-Goとする。
