## 1. 目的

JARTICオープンデータをGoogle Map上の静的・定期更新レイヤーとして将来表示する場合に、利用者が情報源、加工主体、対象時点、更新・権利・検証・停止状態を誤認しない画面要件を定義する。

本書は表示要件を定義するものであり、JARTICオープンデータ、Google Maps Platform、Next.js、Expo、Google Maps SDKの採用・実装を決定しない。

- 第三者権利は利用者の責任で確認する必要がある。

## 4. 基本方針

1. JARTIC月次データをライブ・現在情報として表示しない。
2. `最新公開版`と`現在の交通状況`を明確に分離する。
3. 表示可否、鮮度、検証、権利状態を独立して保持する。
4. 利用者向け状態は独立軸から導出し、`提供停止`を最優先にする。
5. Google Maps標準帰属とJARTIC出典・RouteGarage加工表示を別責務として扱う。
6. 地図表示中は、情報源・提供元更新時点・状態・安全上の限界を固定表示する。
7. 状態は色だけでなく、文字・アイコン・支援技術向けラベルで表現する。
8. 権利不明・期限切れ・検証失敗・提供停止のデータを、警告付きで表示継続しない。
9. 走行中に詳細情報の閲覧、履歴比較、レイヤー切替を促さない。
10. 共有・画像・印刷・エクスポートでも出典・対象年月・加工表示を欠落させない。
11. Web / 将来のiOS / Androidで状態名・意味・優先度を共通化する。

## 5. 用語

| 用語 | 定義 |
| --- | --- |
| 対象年月 | データが対象とする年月。公開日・取得日とは別に扱う |
| 作成基準日 | データ作成の基準日。対象年月がない場合に使用する |
| 提供元更新時点 | JARTICが示す公開更新日・基準時点。RouteGarage取得時刻で代替しない |
| 取得日 | RouteGarageが原本を取得した日 |
| 検証日 | RouteGarageが原本、ハッシュ、変換結果、競合を確認した日 |
| 権利確認日 | 第三者権利台帳の判定を確認した日 |
| 最新公開版 | JARTICが現在公開している版。現在月・現在有効・リアルタイムを意味しない |
| 静的参照情報 | 対象年月・作成基準日時点の参考情報。現在の交通判断には使用しない |
| 加工表示 | RouteGarageが編集・加工した事実を示す表示 |
| 制限表示 | 事前定義・承認された条件と固定注意の下でのみ許可される表示 |
| 提供停止 | 権利、安全、規約、真正性等の理由で情報本体を表示しない状態 |

## 6. 独立状態軸と導出ルール

単一コードで表示可否・鮮度・検証・権利を兼ねない。最低限、次の4軸を独立して保持する。

### 6.1 表示可否（最優先）

| 状態 | 意味 | 情報本体 |
| --- | --- | --- |
| DISPLAYABLE | 通常表示要件を満たす | 条件付き表示可能 |
| LIMITED | 定義済み制限表示ルールの全条件を満たす | 強調度を下げて表示可能 |
| STOPPED | 権利・規約・期限・検証・安全判断等で表示不可 | 非表示 |

優先順位は `STOPPED` > `LIMITED` > `DISPLAYABLE` とする。

### 6.2 鮮度状態

| 状態 | 意味 |
| --- | --- |
| WITHIN_STATIC_BASELINE | 対象年月・提供元更新時点を取得し、静的レイヤー基準内 |
| DELAYED | 公開更新遅延または期待更新なし |
| UPDATE_TIME_UNKNOWN | 提供元更新時点を確認できない |
| EXPIRED | 定義済み有効期限を超過 |
| HISTORICAL | 過去版として明示管理 |

### 6.3 検証状態

| 状態 | 意味 |
| --- | --- |
| VERIFIED | 原本・ハッシュ・変換・対応関係を確認済み、既知の競合なし |
| UNVERIFIED | 検証未完了または根拠不足 |
| CONFLICTED | 複数情報・原本・変換結果に不一致あり |
| VERIFICATION_FAILED | ハッシュ、真正性、変換、対象地点対応等を検証できない |

### 6.4 権利状態

| 状態 | 意味 |
| --- | --- |
| RIGHTS_CONFIRMED | 権利台帳の必要項目と承認が揃う |
| RIGHTS_CONDITIONAL | 条件・期限・表示義務を強制できる場合だけ候補 |
| RIGHTS_REVIEW | 調査中・再確認中 |
| RIGHTS_DENIED | 非許可 |
| RIGHTS_EXPIRED | 失効・再確認期限超過 |

### 6.5 利用者向け状態の導出

利用者向けラベルは、上記4軸を置き換える保存値ではなく、画面表示用の導出結果とする。

導出順序:

1. 権利・契約・必須メタデータを確認する。
2. `STOPPED`条件が1つでもあれば、他軸にかかわらず情報本体を非表示にする。
3. 鮮度状態を判定する。提供元更新時点を取得できない場合、RouteGarage取得時刻で代替しない。
4. 検証状態を判定する。競合・検証失敗を鮮度や上流由来から推測で解消しない。
5. 権利状態を判定する。未確認・失効は許可として扱わない。
6. 通常表示条件を満たさない場合、事前承認済み制限表示ルールがなければ`STOPPED`とする。
7. 複数の不利な条件が成立した場合は最も制限の強い状態を採用する。

例:

- `DELAYED`かつ`RIGHTS_EXPIRED`の場合、利用者向け表示は`提供停止`。
- `HISTORICAL`かつ`VERIFIED`でも、履歴公開権限が未確認なら`提供停止`。
- `UPDATE_TIME_UNKNOWN`は、明示的な制限表示ルールがなければ`提供停止`。

## 7. 情報の表示レベル

### 7.1 固定表示・常時確認可能

JARTICレイヤーの情報本体を表示する間、次を地図画面の固定領域で常時確認可能とする。

- レイヤー名またはデータセット名
- 情報源・提供元
- `静的・月次更新情報`
- 対象年月または作成基準日
- 提供元更新時点
- 鮮度状態
- 検証状態
- 表示可否が`LIMITED`の場合は制限表示である旨
- キャッシュ表示の場合はキャッシュである旨
- 情報欠落・更新遅延・誤差・実際の状況との差異があり得る旨
- 本情報のみを運転判断の唯一の根拠にしない旨
- 詳細操作は安全な場所に停車してから行う旨
- JARTIC出典詳細への導線
- 加工時の`RouteGarage加工`表示

表示密度の都合で文章を短縮する場合も、意味を省略しない。長い説明は詳細へ分離できるが、固定表示には最低限次を残す。

> JARTIC静的情報｜対象: 2026年6月｜提供元更新: 2026年7月1日｜現在情報ではありません｜欠落・遅延・誤差の可能性あり｜運転判断の唯一の根拠にしないでください｜詳細操作は安全な場所に停車してから

文言は例であり、法務・安全レビュー後に確定する。

### 7.2 1操作以内で表示

走行前または安全な場所への停車中に、次を1操作以内で確認できるようにする。

- 正式なデータセット名
- JARTICの正式名称
- JARTIC公開ページURL
- 利用日・参照日
- 提供元更新時点
- RouteGarage取得日
- RouteGarage検証日
- 権利確認状態・確認日
- 表示可否・鮮度・検証・権利の4軸
- 上流提供者・追加帰属
- RouteGarageの加工内容要約
- 欠落・遅延・誤差・位置ずれの詳細
- 利用目的・禁止用途
- 制限表示・キャッシュ表示の許可条件と有効期限
- 過去版である場合の履歴状態

### 7.3 内部運用だけで表示

- 原本ファイル名・ハッシュ
- 利用規約文書ハッシュ
- 証跡参照ID
- 非公開契約・許諾情報
- 承認者の個人情報
- 制限表示・キャッシュ表示の承認記録
- 停止・調査の内部メモ

## 8. 対象画面別要件

### 8.1 地図画面

- レイヤー有効時は固定表示要件を満たす。
- Google Maps標準帰属を覆わない、移動しない、改変しない。
- JARTIC出典表示はGoogle Maps帰属と明確に分離する。
- Google由来、JARTIC由来、RouteGarage独自情報を凡例・ラベル・線種・アイコンで区別する。
- 色だけで区別しない。
- 表示可否が`STOPPED`の場合、情報本体・地物を描画しない。
- `RIGHTS_REVIEW`、`RIGHTS_DENIED`、`RIGHTS_EXPIRED`、`CONFLICTED`、`VERIFICATION_FAILED`、`EXPIRED`は原則`STOPPED`へ導出する。

Web候補:

- デスクトップは地図上部またはサイドパネル上部に固定状態カードを配置する。
- 狭幅はGoogle Maps帰属を覆わない状態バーを配置する。

将来モバイル候補:

- 上部セーフエリアまたはボトムシート最上部へ固定状態を配置する。
- OSジェスチャー領域・ホームインジケータ・Google Maps帰属を覆わない。
- 走行中は詳細シートを展開しない。

### 8.2 レイヤー選択・凡例

- レイヤー名直下に`静的・月次更新`と対象年月を表示する。
- ライブ交通レイヤーと同じカテゴリ・トグル群へ混在させない。
- `最新`だけの表記を禁止する。
- 利用不可時はトグルを無効にし、理由を文字で表示する。
- 停止中レイヤーを初期ONにしない。
- 凡例にはJARTIC由来・RouteGarage加工・過去版を識別する記号を含める。

### 8.3 地物詳細パネル

- 地物表示名
- データセット名
- 対象年月・作成基準日
- 提供元更新時点
- 静的参照情報である旨
- JARTIC出典・上流提供者・追加帰属
- RouteGarage加工表示
- 鮮度・検証・権利・表示状態
- 安全上の注意
- データセット詳細への導線

禁止:

- `現在通行止め`
- `今の規制`
- `リアルタイム`
- `この道路は安全`
- 現在時刻との差だけで鮮度を推測する表示

### 8.4 データセット詳細・出典画面

| 項目 | 必須 |
| --- | --- |
| データセット名・提供元 | 必須 |
| 公開ページURL | 必須 |
| 対象年月・作成基準日 | 必須 |
| 提供元更新時点 | 必須 |
| RouteGarage取得日・検証日 | 必須 |
| 権利確認状態・確認日 | 必須 |
| 表示可否・鮮度・検証・権利の4軸 | 必須 |
| 上流提供者・追加帰属 | 条件付き必須 |
| 加工内容 | 加工時必須 |
| 静的情報・安全注意 | 必須 |
| 欠落・遅延・誤差・位置ずれ | 必須 |
| 履歴・過去版の有無 | 必須 |
| 通報・問い合わせ導線 | 必須 |

日付項目を単一の`更新日`へ統合しない。

### 8.5 履歴・過去版画面

- タイトルに`履歴`または`過去版`を含める。
- 対象年月を明示する。
- 最新公開版との差異を表示する。
- `現在情報へ切り替える`とは表現しない。
- 過去版地図では画面全体に履歴モードを表示する。
- 履歴版と最新公開版を同じ線種・同じラベルで重ねない。
- 走行中に履歴比較を提供しない。

### 8.6 更新遅延・権利確認中・提供停止

更新遅延:

- 旧版の制限表示は、権利・契約・鮮度・検証・承認条件を満たす場合だけ許可する。
- 対象年月、提供元更新時点、更新確認中、制限表示を固定表示する。
- 旧版を現在情報として自動昇格しない。

権利確認中:

- 情報本体・地物を表示しない。
- `権利確認中のため非表示`と表示できる。
- 完了予定日を推測表示しない。

提供停止:

- 停止対象地物を地図から除去する。
- 直前表示内容をキャッシュで残さない。
- 公開可能な範囲で停止状態を表示する。
- `データなし`と`提供停止`を区別する。

### 8.7 データなし・取得失敗・検証失敗

| 状態 | 利用者向け表示 | 情報本体 |
| --- | --- | --- |
| 対象データなし | 対象年月にデータなし | 非表示 |
| 取得失敗 | 現在取得失敗中 | 原則非表示。全キャッシュ条件充足時のみ制限表示 |
| 検証失敗 | 検証できないため停止 | 非表示 |
| ハッシュ不一致 | 提供停止 | 非表示 |
| 権利状態失効 | 権利再確認のため停止 | 非表示 |

失敗を通常の空データと同じ表示にしない。

## 9. 取得失敗時のキャッシュ再表示

取得済み旧版・キャッシュを表示できるのは、次をすべて満たす場合に限る。

1. 利用規約・契約でキャッシュ保存と再表示が許可されている。
2. 提供元更新時点を取得済みである。
3. 情報種別ごとに事前承認されたキャッシュ有効期限内である。
4. 契約停止、規約変更、提供元による無効化・撤回、改ざん・完全性懸念がない。
5. 上流由来、調達経路、検証状態を追跡でき、競合がない。
6. `現在取得失敗中`、`キャッシュ情報`、`提供元更新時点`を固定表示できる。
7. 情報種別ごとの制限表示ルール、承認者、承認記録がある。

1つでも満たさない場合は`STOPPED`とし、情報本体を表示しない。

有効期限内でも次の場合は必ず停止する。

- 契約停止または規約変更で表示権限を確認できない。
- 提供元が対象データを無効・撤回した。
- 改ざん、破損、完全性、対象地点対応に懸念がある。
- 権利状態が未確認・失効・非許可である。
- 安全な表示可否を判断できない。

## 10. 共有・スクリーンショット・印刷・エクスポート

公開候補とする場合、出力物に次を含める。

- データセット名
- 対象年月・作成基準日
- 提供元更新時点
- JARTIC出典
- RouteGarage加工表示
- 静的情報である旨
- 出力日
- Google Maps由来コンテンツを含む場合のGoogle Maps帰属

No-Go条件:

- 帰属・対象年月・提供元更新時点が出力範囲外になる。
- Google Maps帰属を画像加工で除去する。
- 第三者権利台帳でエクスポートが未確認・非許可。
- 非公開証跡・内部ID・利用者の正確な位置を意図せず含む。
- 停止・失効中の地物を出力する。

## 11. 禁止表現

月次・静的レイヤーでは次を使用しない。

- リアルタイム
- 現在の交通情報
- 最新交通情報
- 現在の渋滞
- 現在通行止め
- 今の規制
- 最新の規制
- 通行可能です
- 安全です
- この情報に従えば問題ありません
- 常に正確です
- 公式が保証しています

`最新公開版`を表示する場合は、対象年月と現在情報ではない旨を同時表示する。

## 12. 出典・加工・安全注意の文言候補

出典:

> 出典: 「{データセット名}」（公益財団法人日本道路交通情報センター）（{公開ページURL}、{利用日}利用）

加工表示:

> JARTIC公開データをRouteGarageが表示用に編集・加工しています。

静的情報・限界:

> 対象年月時点の静的情報です。現在の渋滞、事故、通行止め、緊急規制を示すものではなく、欠落・遅延・誤差や実際の状況との差異があり得ます。

安全注意:

> 本情報のみを運転判断の唯一の根拠にしないでください。詳細操作は安全な場所に停車してから行ってください。

最終文言は法務・安全・運用レビュー後に確定する。

## 13. Google Maps帰属との責務分離

Google Maps帰属:

- Google Maps Platform由来コンテンツの帰属として扱う。
- Googleが提供する帰属を削除、非表示、隠蔽、改変しない。
- 公式のサイズ、コントラスト、アクセシビリティ要件へ従う。

JARTIC出典・加工表示:

- RouteGarageが追加する第三者データの出典・加工表示として扱う。
- Google MapsロゴだけでJARTIC出典を代替しない。
- JARTIC出典をGoogleがJARTICデータを提供・保証したように配置しない。
- 一つの曖昧な`提供元`表示へ統合しない。

小画面でも両方を判読できない場合、そのレイアウトではJARTICレイヤーを表示しない。

## 14. アクセシビリティ要件

- 状態を色だけで表現しない。
- 状態ラベルへ文字と意味のあるアイコンを併用する。
- スクリーンリーダー向けに、レイヤー名、対象年月、提供元更新時点、4軸状態、安全注意を読み上げる。
- アイコン操作にアクセシブルネームを付与する。
- 文字と背景のコントラストはWCAG 2.2 AA相当を目標とする。
- キーボードだけで状態、凡例、詳細、閉じる操作へアクセスできる。
- 詳細表示時のフォーカス移動・復帰を定義する。
- 点滅、自動スクロール、強制アニメーションで状態を伝えない。
- 状態変化通知は連続読み上げを避ける。

## 15. レスポンシブ要件

デスクトップ:

- 地図を隠しすぎない固定状態カードまたはサイドパネルを使用する。
- Google Maps帰属を覆わない。
- キーボード操作と200%ズームを確認する。

タブレット:

- 縦横とも固定安全注意・対象年月・状態を維持する。
- サイドパネルとボトムシートの切替候補を検討する。

モバイル:

- `静的情報`、対象年月、提供元更新時点、状態、安全注意を優先表示する。
- 出典詳細を折りたたんでも、提供元・加工有無・安全注意への導線を残す。
- セーフエリアとOSジェスチャー領域を避ける。
- 重要表示と両方の帰属を維持できない画面サイズではレイヤーを表示しない。

## 16. 走行状態別要件

| 状態 | 許可する表示・操作 |
| --- | --- |
| 走行前 | レイヤー選択、詳細、出典、履歴確認が可能 |
| 停車中 | 走行前と同等。停車判定の実装は別Issue |
| 走行中 | 固定安全注意・対象年月・提供元更新時点・導出状態の最小表示のみ。詳細展開・履歴比較・レイヤー切替を促さない |
| 状態不明 | 走行中と同等の安全側表示候補 |

- 走行中に操作を要求するエラー回復を設けない。
- 出典詳細の閲覧を走行中に要求しない。
- 静的情報を現在規制として音声案内しない。
- 強い警告音や点滅で更新遅延・停止を通知しない。

## 17. 受け入れ条件

正常系:

- 情報本体表示中に、情報源、対象年月、提供元更新時点、鮮度、検証、固定安全注意を確認できる。
- JARTIC出典・加工表示とGoogle Maps帰属を確認できる。
- Google、JARTIC、RouteGarage由来情報を区別できる。

状態合成:

- 表示可否・鮮度・検証・権利を独立保持している。
- `STOPPED`が他の状態より優先される。
- 更新遅延中の権利失効・競合・検証失敗で情報本体が残らない。
- 過去版・キャッシュを単一状態コードだけで表示許可しない。

取得失敗:

- 旧版再表示は7つのキャッシュ条件をすべて満たす場合だけ可能。
- 条件不足・撤回・完全性懸念・期限切れ・権利失効時は停止する。
- 取得失敗、キャッシュ表示、提供元更新時点を固定表示する。

境界値:

- 長いデータセット名・上流提供者名でも帰属が欠落しない。
- 対象年月・提供元更新時点・取得日が異なる場合も混同しない。
- 小画面、200%ズーム、文字拡大、ライト・ダークモードで重要表示を維持する。

異常系:

- 出典・権利・提供元更新時点・検証情報が欠落している場合は原則停止する。
- Google Maps帰属を表示できない場合はGoogle Mapを表示しない。
- JARTIC出典・固定安全注意を表示できない場合はJARTICレイヤーを表示しない。

共有・印刷:

- 出典、対象年月、提供元更新時点、加工表示が出力に含まれる。
- 停止・非許可・未確認データを出力できない。
- 正確な利用者位置・内部証跡を意図せず含まない。

アクセシビリティ:

- キーボードだけで操作可能。
- スクリーンリーダーで情報源・対象年月・4軸状態・安全注意を理解できる。
- 色覚だけに依存せず状態を識別できる。
- フォーカスと帰属・注意文のコントラストを維持する。

## 18. Go / No-Goゲート

次をすべて満たす場合のみ画面基本設計候補へ進める。

1. 権利台帳がGo候補または強制可能な条件付きGoである。
2. 表示可否・鮮度・検証・権利状態を独立保持できる。
3. `STOPPED`を最優先に導出できる。
4. 対象年月・作成基準日・提供元更新時点を表示できる。
5. JARTIC出典、加工表示、追加帰属を表示できる。
6. Google Maps標準帰属を維持できる。
7. Google・JARTIC・RouteGarage由来情報を区別できる。
8. 固定安全注意を情報本体表示中に維持できる。
9. 更新遅延、過去版、制限表示、キャッシュ、権利確認中、停止を区別できる。
10. 取得失敗時の7キャッシュ条件を強制できる。
11. 色だけに依存しない。
12. Web・将来モバイル・拡大表示で重要表示を維持できる。
13. 走行中に詳細操作を促さない。
14. 共有・印刷時に出典・対象年月・提供元更新時点を維持できる。
15. 欠落・失効・競合・検証失敗時に情報本体を停止できる。
16. 人間・法務・運用・安全・アクセシビリティレビューが完了している。

1項目でも未確認・実現不能の場合は保留またはNo-Goとする。
