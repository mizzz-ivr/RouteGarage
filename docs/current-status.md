## 確定済みの横断方針

### 情報表示

- 表示可否、鮮度、検証、権利を独立状態として保持する。
- `STOPPED` > `LIMITED` > `DISPLAYABLE`を適用する。
- 権利不明、期限切れ、競合、検証失敗、安全判断不能では情報本体を非表示にする。
- 情報本体表示中は出典、加工、対象年月、提供元更新時点、参考情報、安全注意を固定表示する。

### 走行安全

- 投稿、編集、公開変更、画像操作等は停車中利用を原則とする。
- 走行状態不明時は閲覧中心へ制限する。
- 位置・交通情報を運転判断の唯一の根拠として表示しない。

### 位置・走行履歴

- 公開初期値は非公開または限定公開とする。
- 正確な開始・終了地点を公開前提で恒久保存・表示しない。
- 生活拠点、反復訪問地点、道路形状、複数記録からの再推定を評価する。
- Webでは外部キャプチャを完全に防止できる前提を置かず、通常表示をプライバシーセーフにする。
- 公開Repository・一般ログへ位置情報・走行履歴・EXIF位置情報を保存しない。

### 保持・削除

- 原本から全派生物まで多対多系譜で追跡する。
- 表示停止を物理削除より先に実施する。
- 項目・地物単位の削除を原本、派生物、履歴、キャッシュ、バックアップ、外部保存先へ伝播する。
- 保持上限、法務確認済み最低保持期間、再確認期限を分離する。
- バックアップ実失効・不存在確認前に削除完了証跡を発行しない。
- 復旧時に削除墓標、再取得拒否、停止、権利、法的保全の5台帳を再適用する。
- 法的保全解除後に保留中の削除義務を再開する。

## Issue #121の公式根拠

### JARTIC

- 各情報は毎月月初に更新される。
- 更新前の情報は公開ページから取得できなくなる。
- 出典表示と加工表示が必要。
- 第三者権利は利用者責任で確認する。
- データ・利用規約は変更、移転、削除、改定される場合がある。
- JARTIC資料に一律の保存期間・削除SLAは記載されていない。

### 個人情報保護委員会

- 個人情報に一律の保存期間は定められていない。
- 利用目的に応じて期間を設定し、不要になった場合は必要以上に長期化させず消去する考え方が示されている。
- 本Issueでは個人利用者データの最終保持期間を決定しない。

## Issue #121の暫定保持上限候補

| 分類 | 内部暫定候補 |
| --- | --- |
| 取得原本 | 取得から90日、現行版と直前2公開サイクルまで |
| 説明書・規約スナップショット | 最終利用または関連削除完了から365日 |
| 正規化・加工データ | 親の早い期限、最大90日 |
| 表示用データ | 現行承認版のみ。旧版アクティブ保持0日 |
| ロールバック隔離 | 最大7日 |
| 履歴 | 初期値は保持しない。個別承認時最大90日 |
| 一時ファイル | 処理終了から24時間、絶対上限72時間 |
| キャッシュ・インデックス | TTL最大24時間 |
| 最小監査メタデータ | 365日 |
| 削除墓標・再取得拒否 | 初回最大365日、90日ごと再確認 |
| 削除完了証跡 | 365日 |
| バックアップ実失効 | 削除確定から35日以内 |

これらは法定期間・契約期間・JARTIC要求値ではない。provider、契約、第三者権利、技術構成、法務判断確定後に再計算する。

## 再確認期限候補

- 取得・公開判定前: 毎回
- JARTIC月次更新検知後: 3営業日以内
- 毎月7日までに更新確認不能: `UPDATE_DELAYED`
- 利用規約: 取得前毎回、定期7日ごと
- 第三者権利: 公開判定前毎回、最終確認から最大30日
- 全権利台帳棚卸し: 90日ごと
- 通常例外・法的保全: 30日ごと

## 応答・削除SLA候補

### 通常の削除確定

- 新規配信・再取得・再生成停止: 15分以内
- `DELETION_PENDING`: 4時間以内
- 削除計画承認: 1営業日以内
- オンライン本体・派生物削除: 3営業日以内
- 外部保存先削除確認: 7暦日以内
- バックアップを含む削除完了: 35暦日以内

### 個人情報・正確位置・秘密情報混入

- 新規配信停止: 15分以内
- アクセス遮断・隔離: 1時間以内
- 影響範囲特定: 4時間以内
- オンライン削除: 24時間以内
- 外部保存先削除: 72時間以内
- バックアップ実失効: 35日以内または承認済みのより短い期限

### `LEGAL_HOLD`

- 30日ごとに法務再確認する。
- 初回保全期間の内部候補は最大90日とする。
- 解除後4時間以内に削除義務を再判定し、1営業日以内に削除を再開する。

## Go / No-Go

次を満たせない場合は基本設計・保存開始・公開をNo-Goとする。

- 全分類の有効保持上限を計算できない。
- 法的最低保持期間の根拠・承認がない。
- 規約・権利・公開版を期限内に再確認できない。
- 表示停止・隔離・削除計画SLAを満たせない。
- 外部保存先を7日以内に削除確認できない。
- バックアップを35日以内に実失効確認できない。
- 削除完了前に完了証跡を発行する。
- `LEGAL_HOLD`へ期限・再確認日・解除後削除計画がない。
- 個人情報・位置・秘密情報混入時の緊急SLAを満たせない。
