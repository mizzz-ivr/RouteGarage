## 確定済みの横断方針

### 情報表示

- 表示可否、鮮度、検証、権利を独立状態として保持する。
- `STOPPED` > `LIMITED` > `DISPLAYABLE`を適用する。
- 権利不明、期限切れ、競合、検証失敗、安全判断不能では情報本体を非表示にする。
- JARTIC情報本体表示中は出典、加工、対象年月、提供元更新時点、参考情報、安全注意を固定表示する。

### 走行安全

- 投稿、編集、公開変更、画像操作等は停車中利用を原則とする。
- 走行状態不明時は操作可能とみなさず閲覧中心へ制限する。
- 位置・交通情報を運転判断の唯一の根拠として表示しない。

### 位置・走行履歴

- 公開初期値は非公開または限定公開とする。
- 正確な開始・終了地点を公開前提で恒久保存・表示しない。
- 自宅・職場・反復訪問地点を推定されるリスクを優先して低減する。
- 公開Repository・一般ログへ位置情報・走行履歴・EXIF位置情報を保存しない。

### 保持・削除

- 原本から全派生物まで多対多系譜で追跡する。
- 表示停止を物理削除より先に実施する。
- 原本・項目・地物単位の削除を派生物、履歴、キャッシュ、バックアップ、外部保存先へ伝播する。
- バックアップ実失効・不存在確認前に削除完了証跡を発行しない。
- 復旧時に削除墓標、再取得拒否、停止、権利、法的保全の5台帳を再適用する。
- 法的保全解除後に保留中の削除義務を再開する。

## Issue #119で定義するプライバシー境界

### 位置分類

| 分類 | 内容 | 公開・一般共有 |
| --- | --- | --- |
| `EXACT_PRIVATE` | 正確な現在位置、原GPS、正確な開始終了地点、原走行軌跡 | No-Go |
| `SENSITIVE_DERIVED` | 生活拠点候補、反復訪問、長時間滞在、推定自宅・職場 | No-Go |
| `PRIVACY_REDUCED` | 承認済み変換後の経路・地域・地点 | 条件付き候補 |
| `PUBLIC_NON_LOCATION` | 位置を含まない公開可能な概要 | 候補 |

分類不能時は`EXACT_PRIVATE`相当とする。

### 再推定評価

次を組み合わせて生活拠点・行動を再推定できないか確認する。

- 開始・終了地点
- 道路形状・一本道・袋小路
- 時刻・曜日・滞在傾向
- 反復訪問
- 複数走行記録の共通端点
- 地図中心・ズーム・地名・ランドマーク
- 画像EXIF・説明文・施設名・車両情報

単純な座標丸め・円表示だけで`PRIVACY_REDUCED`とは扱わない。

### ぼかし・変換

- 機微地点周辺の経路除去、端点切り詰め、粗粒度化、集約、公開用データ分離を後続設計候補とする。
- 正確な開始・終了地点を公開しない。
- 複数記録を組み合わせても生活拠点を推定しにくいことを確認する。
- 変換後に経路の公開価値が成立しない場合、位置を含まない概要だけを候補とする。
- 無作為移動で実際に走行していない道路を示す方式は、真正性評価なしに採用しない。

### 具体値の決定

ぼかし距離、時間、訪問回数、滞在時間、ズーム等は未確定。

後続設計で次を評価する。

- 都市・郊外・過疎地域差
- 道路・建物密度
- 一本道・私道・単独施設
- 単一・複数記録の再推定成功率
- 共有画像解像度・ズーム・ラベル
- 走行距離に対する非表示割合
- 公開範囲
- 匿名・合成データによる攻撃者視点評価
- 法務・プライバシー・セキュリティレビュー

具体値は人間承認前にGoとしない。

## 外部キャプチャ境界

### Web

- OSスクリーンショット・画面収録を確実に防止できる前提を置かない。
- 公開・共有可能な画面は通常表示の時点でプライバシーセーフにする。
- 右クリック禁止、キー操作禁止、透かし、注意文を最低保護基準の代替にしない。
- 印刷・PDFでは印刷専用表示または`@media print`で精密位置・原走行履歴を除外する。

### iOS / Android

次を独立能力として扱う。

1. キャプチャ抑止
2. キャプチャ検知
3. アプリスイッチャー・バックグラウンド保護

- 検知可能でも抑止済みとは扱わない。
- API・ライブラリの存在だけで全端末・全経路を保護済みと判断しない。
- 対象OS・端末・画面状態・ミラーリング・画面共有・バックグラウンドを実機検証する。
- 保護利用不可・失敗・状態不明時はプライバシーセーフ表示へフォールバックする。

### フォールバック

1. 精密位置・機微情報を非表示
2. 承認済み`PRIVACY_REDUCED`へ切替
3. 位置を含まない概要だけ表示
4. 画面・共有・印刷・エクスポートをブロック

警告表示だけで精密情報を継続表示しない。

## 共有・印刷・エクスポート

- 共有前プレビューと実出力に同じデータ版・変換版・描画条件を使用する。
- 公開範囲、変換結果、地図中心・ズーム、帰属、対象時点を確定前に確認する。
- URL、OGP、サムネイル、HTML、クライアントデータへ原座標を埋め込まない。
- 一般利用者向けCSV / GeoJSON等へ精密位置・原走行履歴を含めない。
- 削除・取消・公開範囲変更を共有URL・OGP・キャッシュへ伝播する。
- 印刷CSS未適用・プレビュー不一致・変換失敗時は出力No-Go。

## テスト方針

- 実利用者の位置・走行履歴を使用しない。
- 承認済みの合成・匿名データを使用する。
- 単一記録と複数記録の再推定を確認する。
- 都市・郊外・過疎地域、短距離、一本道を確認する。
- Web印刷・PDF・JavaScript無効時を確認する。
- iOS / Androidのスクリーンショット、録画、ミラーリング候補、アプリスイッチャー、失敗時を確認する。
- プレビューと実出力、削除後のURL・OGP・キャッシュ停止を確認する。
