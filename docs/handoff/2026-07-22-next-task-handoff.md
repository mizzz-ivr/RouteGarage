- RouteGarage受信時刻は上流情報の更新時刻の代替にしない。

### PR #90 P2: 契約経路と情報の由来を分離する

- 上流由来と調達経路を別軸で管理する。
- 契約の有無を正確性・検証済み状態の根拠にしない。

### PR #92 P1: 状態判定優先順位を定義する

- 状態を `表示可否`、`鮮度状態`、`検証状態` の3軸へ分離。
- `提供停止` > `制限表示` > `表示可` の順で制限の強い状態を優先する。

### PR #92 P2: 事業者一次観測を分類する

- 上流由来に `事業者一次観測` を追加。
- 自社センサー・設備・現地要員による未加工一次情報を対象とする。

### PR #92 P2: 道路管理者の一次観測と公式発表を分離する

- 正式発表として内容が確定しているかを最初に判定する。
- 道路管理者が正式に公表した情報は `公式発表`。
- 正式判断・発表前の未加工観測値は `事業者一次観測`。

### PR #92 P2: 取得失敗時のキャッシュ表示境界を定義する

- 取得失敗中の通常表示を禁止する。
- 権利、更新時刻、有効期限、完全性、検証状態、固定警告、承認記録をすべて満たす場合のみ `制限表示`。
- 条件不足、契約停止、規約変更、撤回、完全性懸念、安全判断不能の場合は `提供停止`。
