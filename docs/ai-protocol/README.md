## 構成
- `PROMPT.md` / `PROMPT.txt`: AIへの共通指示
- `core/`: リポジトリ共通ルール
- `project-overlays/`: プロジェクト・レイヤ別追加ルール
- `templates/`: Issue/PR/ADR/ログ雛形

## 運用原則
- ウォーターフォール開発・Issue駆動を維持する
- 仕様確定前は実装しない
- AI生成物は必ず人間レビューを行う
- 日本語運用・証跡保存を徹底する
