# Issue #138 MVP要件delta

## 1. 目的

`docs/requirements/mvp-requirements.md` の既存ガレージ要件 `FR-GARAGE-01`〜`03` を壊さず、愛車の整備・給油・走行距離履歴を追加する場合のレビュー用差分を定義する。

Issue #138の人間レビュー承認前にMVP正本へ直接統合しない。

## 2. 主要ユースケース追加候補

既存主要ユースケースへ次を追加する候補とする。

- ユーザーが走行後または停車中に、愛車の整備・給油・走行距離を記録する。
- ユーザーが過去の整備・給油履歴を車両別に確認する。
- 十分な給油データがある場合、満タン法による区間燃費を確認する。
- ユーザー自身が設定した次回メンテナンス日/距離の目安を確認する。

## 3. MVP In Scope追加候補

- 愛車ごとの整備履歴管理
- 愛車ごとの給油履歴管理
- 入力済み走行距離の時系列整合性確認
- 有効条件を満たす区間燃費表示
- ユーザー設定の次回メンテナンス目安
- 車両別履歴一覧・絞り込み

## 4. ガレージ機能要件追加候補

### 整備

- `FR-GARAGE-HIST-01`: 所有車両へ整備記録を追加できること。
- `FR-GARAGE-HIST-02`: 本人が整備記録を閲覧・編集・削除できること。
- `FR-GARAGE-HIST-03`: 整備カテゴリ、実施日、作業内容を必須として扱えること。
- `FR-GARAGE-HIST-04`: 走行距離、店舗名、費用、メモ、次回目安を任意入力できること。
- `FR-GARAGE-HIST-05`: 違法改造を助長する表示・導線を追加しないこと。

### 給油

- `FR-GARAGE-FUEL-01`: 所有車両へ給油記録を追加できること。
- `FR-GARAGE-FUEL-02`: 給油日、走行距離、給油量、満タンフラグを必須として扱えること。
- `FR-GARAGE-FUEL-03`: 合計金額、単価、個人メモを任意入力できること。
- `FR-GARAGE-FUEL-04`: 給油量0以下を有効給油として扱わないこと。
- `FR-GARAGE-FUEL-05`: 本人が給油記録を編集・削除できること。

### 走行距離

- `FR-GARAGE-ODO-01`: 車両単位で入力済み走行距離の時系列整合性を確認できること。
- `FR-GARAGE-ODO-02`: 直前値と同値の走行距離を許容できること。
- `FR-GARAGE-ODO-03`: 距離逆転を通常記録として無条件確定しないこと。
- `FR-GARAGE-ODO-04`: 訂正・メーター交換等を通常記録と区別できること。
- `FR-GARAGE-ODO-05`: 距離整合性不明時に燃費・距離目安を断定表示しないこと。

### 燃費

- `FR-GARAGE-ECO-01`: 満タン法の成立条件を満たす区間だけ燃費を算出できること。
- `FR-GARAGE-ECO-02`: 部分給油を挟む場合は対象区間の給油量を合算できること。
- `FR-GARAGE-ECO-03`: 算出不能と0km/Lを区別できること。
- `FR-GARAGE-ECO-04`: 元履歴の訂正・削除後に派生燃費を再評価できる設計へ引き継ぐこと。

### 次回目安

- `FR-GARAGE-REM-01`: ユーザーが次回目安日を任意設定できること。
- `FR-GARAGE-REM-02`: ユーザーが次回目安走行距離を任意設定できること。
- `FR-GARAGE-REM-03`: 入力済み有効値との比較状態を表示できること。
- `FR-GARAGE-REM-04`: メーカー推奨値や安全判定を自動生成しないこと。

## 5. 非機能要件追加候補

### 安全

- `NFR-GARAGE-SAFE-01`: 整備・給油記録の作成/編集/削除は停車中または走行後の利用を前提とする。
- `NFR-GARAGE-SAFE-02`: 整備履歴から走行可否・故障・車検適合を自動判定しない。
- `NFR-GARAGE-SAFE-03`: 次回目安をメーカー推奨値または安全保証値として表示しない。

### プライバシー

- `NFR-GARAGE-PRIV-01`: 履歴を本人限定とする。
- `NFR-GARAGE-PRIV-02`: 公開車両プロフィールから非公開履歴へアクセスできないこと。
- `NFR-GARAGE-PRIV-03`: GPS/店舗座標/VIN/ナンバープレート等をMVP必須項目にしない。

### 整合性

- `NFR-GARAGE-DATA-01`: 数量・距離・費用の無効値を派生計算へ使用しない。
- `NFR-GARAGE-DATA-02`: 訂正・削除時に関連派生値を再評価できること。
- `NFR-GARAGE-DATA-03`: 同時編集による古い値の無条件上書きを避ける設計へ引き継ぐこと。

## 6. MVP Out of Scope追加候補

- OBD/ECU/ドラレコ連携
- GPS自動走行距離取得
- VIN/メーカーAPIによる自動車両・部品取得
- レシートOCR
- 整備画像/レシート画像保存
- 店舗予約/決済
- AI故障診断・整備安全診断
- 走行可否自動判定
- 車検適合保証
- 整備/給油/走行距離履歴の公開共有
- 整備事業者向け業務機能

## 7. 正本統合条件

Issue #138の人間レビューで以下を確認した後にMVP正本へ統合する。

- 整備/給油の必須・任意項目
- 走行距離逆転とメーター交換の扱い
- 満タン法の燃費条件
- 次回目安の安全境界
- 本人限定認可
- 車両アーカイブ/削除時の履歴方針
- 画面deltaとの整合
