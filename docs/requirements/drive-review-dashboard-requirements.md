# ドライブ振り返り・統計ダッシュボード 要件定義（Issue #141）

## 1. 目的

RouteGarageに保存された本人の走行記録・訪問記録・コレクション進捗を使い、月間・年間・任意期間のドライブ活動を安全かつプライベートに振り返れるダッシュボードを定義する。

本機能はランキング、競争、運転技術評価、走行量の増加を促すことを目的としない。

## 2. 背景

既存要件には以下がある。

- 走行記録
- 行きたいスポット / ドライブプラン
- ドライブストーリー
- ドライブコレクション / 訪問進捗
- Garageプロフィール
- 整備 / 給油 / 走行距離履歴

一方、ユーザーがこれらを横断して「自分が最近どう走ったか」を振り返る統合ビューは未定義である。

## 3. 対象ユーザー

- 月ごとのドライブ回数・距離を振り返りたいユーザー
- 車両別の利用傾向を確認したいユーザー
- 最近訪れたスポットや達成したコレクションを見返したいユーザー
- 過去の記録から次のドライブ候補へ手動で移動したいユーザー

## 4. 前提・仮定

### 4.1 確定前提

- 集計対象は本人がRouteGarageへ保存した有効データに限定する。
- 新しいGPS/OBD/外部provider取得は行わない。
- 統計ダッシュボードは本人限定をMVP既定とする。
- ドライブプランの予定値を走行実績へ混ぜない。
- 正確な生活拠点・頻出地点を推測表示しない。

### 4.2 仮定

- 走行記録の日付・距離を基本集計元とする。
- 訪問記録はIssue #132の自己申告という性質を継承する。
- 車両別集計は走行記録が車両参照を持つ場合のみ成立する。

### 4.3 要確認

- 任意期間フィルターをMVPに含めるか。
- 記録0件の月をグラフ上で0として表示するか、データなしとして扱うか。
- 「過去の思い出」セクションをMVPへ含めるか。
- 車両アーカイブ後に車両名をどの粒度で残すか。
- 集計値を都度計算するか、派生値として保持するか。

## 5. 用語

| 用語 | 定義 |
| --- | --- |
| 対象期間 | 集計対象となる日付範囲 |
| 有効走行記録 | 削除済み等を除き、本人が閲覧可能な走行実績記録 |
| 距離入力済み記録 | 有効走行記録のうち実績距離が入力されているもの |
| 統計値 | 有効な元データから導出する派生表示値 |
| 算出不能 | 必要データ不足・不整合等により数値を確定できない状態 |
| 粗いエリア | 生活拠点を特定できない粒度で表示可能とレビューされた地域表現 |

## 6. 機能範囲

### 6.1 期間サマリー

表示候補:

- ドライブ回数
- 合計走行距離
- 平均走行距離
- 最長ドライブ距離
- 記録のある日数
- 利用車両数

期間候補:

- 今月
- 先月
- 今年
- 任意期間

### 6.2 月別推移

- 月ごとのドライブ回数
- 月ごとの合計走行距離
- 期間内の月を時系列で表示する
- 欠損・算出不能・0件を同一表現にしない

### 6.3 車両別振り返り

表示候補:

- 車両別ドライブ回数
- 車両別合計走行距離
- 車両別最終利用日
- 車両別期間内利用比率候補

ただし、Garage整備費用・給油履歴・燃費等はIssue #138の本人限定境界を継承し、本機能へ自動統合しない。

### 6.4 スポット / コレクション振り返り

表示候補:

- 対象期間の訪問登録数
- 対象期間の新規訪問スポット数
- 保存中コレクション進捗への導線
- 対象期間に達成したコレクション数候補
- 最近訪問登録したスポット

訪問記録は運営確認済み実績ではなく自己申告として扱う。

### 6.5 エリア振り返り

粗いエリア情報が安全・プライバシー要件を満たす場合だけ表示候補とする。

禁止:

- 自宅周辺の頻出表示
- 勤務先周辺の頻出表示
- 車両保管場所の推測
- 正確な座標ヒートマップ
- 最頻出地点ランキング

### 6.6 最近の振り返り

- 最近の走行記録
- 最近の訪問登録
- 最近達成したコレクション候補
- 詳細画面への導線

### 6.7 次のドライブへの導線

許容:

- 行きたいスポット一覧へ移動
- 保存済みコレクションへ移動
- 過去の走行記録から、ユーザー操作でドライブプラン作成/複製候補へ移動

禁止:

- 統計値だけを根拠に安全なルートを自動決定する
- 走行距離を増やすよう煽る
- 速度・時間を改善するよう促す

## 7. 機能要件

### 7.1 集計

- `FR-REVIEW-01`: 本人の有効走行記録を対象期間で集計できること。
- `FR-REVIEW-02`: ドライブ回数を有効走行記録件数として算出できること。
- `FR-REVIEW-03`: 距離入力済み記録だけから合計走行距離を算出できること。
- `FR-REVIEW-04`: 平均走行距離の分母を距離入力済み有効記録件数として扱えること。
- `FR-REVIEW-05`: 最長ドライブ距離は距離入力済み有効記録だけを対象にできること。
- `FR-REVIEW-06`: 0件・0km・距離未入力・算出不能を区別できること。

### 7.2 月別

- `FR-REVIEW-07`: 月単位で走行記録件数と合計距離を集計できること。
- `FR-REVIEW-08`: 月初/月末/年跨ぎの期間境界を一貫して扱えること。
- `FR-REVIEW-09`: タイムゾーン基準を後続設計で明示し、同一レコードが異なる月へ重複計上されないこと。

### 7.3 車両別

- `FR-REVIEW-10`: 車両参照を持つ走行記録を車両単位で集計できること。
- `FR-REVIEW-11`: 車両参照がない記録を別車両へ推測配分しないこと。
- `FR-REVIEW-12`: 車両削除・アーカイブ後に非公開Garage情報を復活表示しないこと。

### 7.4 訪問 / コレクション

- `FR-REVIEW-13`: 本人の訪問記録とコレクション進捗から振り返り導線を構成できること。
- `FR-REVIEW-14`: 停止・非公開・削除されたスポットの本文・画像・正確位置を統計画面から復活させないこと。
- `FR-REVIEW-15`: 訪問登録を運営確認済み実績として表現しないこと。

### 7.5 認可 / 公開

- `FR-REVIEW-16`: 統計ダッシュボードを本人だけが閲覧できること。
- `FR-REVIEW-17`: 公開プロフィール、公開投稿、公開ストーリーへ統計値を自動埋め込みしないこと。
- `FR-REVIEW-18`: 他ユーザーIDや統計IDの直指定で個人統計を取得できないこと。

### 7.6 安全

- `FR-REVIEW-19`: 速度・最速・最短時間・ランキング・ストリーク等の競争指標を提供しないこと。
- `FR-REVIEW-20`: 統計を運転技術や安全性の評価に使用しないこと。
- `FR-REVIEW-21`: 走行中の操作を促す通知・導線を本機能から提供しないこと。

## 8. データ整合性

- 集計元が編集された場合、影響する期間・車両・スポット統計を再評価する。
- 集計元が削除された場合、削除対象を集計から除外する。
- 距離未入力を0kmとして補完しない。
- 計画距離・予定距離を実績距離へ混入しない。
- 参照先停止後に古い表示データをキャッシュから復活させない。
- 同じ走行記録を複数データソースから二重計上しない。

## 9. 公開範囲・認可

MVPは本人限定。

公開画面へ含めてはならない候補:

- 月間合計距離
- 年間合計距離
- 車両別走行距離
- 最終利用日
- 頻出エリア
- 訪問履歴
- コレクション達成履歴

将来共有する場合は、共有対象・粒度・期間・失効・削除・再公開について別要件でレビューする。

## 10. プライバシー・安全

- 正確位置を新規取得しない。
- 正確な生活拠点を推測しない。
- 「もっと走ろう」「今月は少ない」等の走行量評価を避ける。
- 速度や最短時間に意味づけしない。
- 統計値を保険・安全・運転能力の判断材料として保証しない。

## 11. 対象外

- ユーザー間ランキング
- 距離/速度/時間競争
- ストリーク
- リアルタイムトラッキング
- GPS自動取得
- OBD連携
- AI運転評価
- 自動安全診断
- SNS向け統計共有カード
- 外部分析provider導入
- DB/API/UI実装

## 12. 受け入れ条件

- 期間、月別、車両別、訪問/コレクションの責務が定義されている。
- 0 / 未入力 / 算出不能を区別できる。
- 編集・削除・参照停止時の再評価が定義されている。
- 本人限定の認可境界が定義されている。
- 生活拠点推測・競争指標を除外できている。
- 既存機能の公開範囲を弱めていない。
- 外部providerや実装を先行導入していない。

## 13. テスト観点

### 正常系

- 1件の走行記録
- 複数件の走行記録
- 複数月
- 複数車両
- 訪問記録あり
- コレクション達成あり

### 異常系

- 距離未入力
- 削除済み走行記録
- 非所有ユーザーアクセス
- 計画距離の混入
- 参照先停止後の古い表示

### 境界値

- 対象期間0件
- 0kmの有効走行記録
- 距離未入力
- 月初/月末
- 12月/1月跨ぎ
- ユーザー日付境界
- 車両削除/アーカイブ

### 回帰

- 走行記録の公開範囲
- Issue #132の訪問/コレクション非公開情報
- Issue #138のGarage履歴非公開情報
- 走行中操作禁止
- provider未選定方針

## 14. 後続設計へ渡す事項

- 期間境界とタイムゾーン
- 集計クエリ/派生値キャッシュ方式
- 大量レコード時のページング/集計性能
- 車両アーカイブ後の表示名
- グラフ表示ライブラリ採用可否
- アクセシビリティ上のグラフ代替表現
- 統計再計算の整合性保証
